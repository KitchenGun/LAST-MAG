# Gulag-project 콘셉트 결정서

## 문서 목적

이 문서는 모든 세부 기획서가 따라야 하는 확정 기준을 모은다. 다른 문서와 내용이 충돌하면 아래 우선순위를 적용한다.

1. 현재 프로젝트에서 합의한 결정
2. `Gulag-project` Google 기획 문서
3. 실제 Unity 프로젝트 환경

이 문서는 게임 규칙과 제작 범위를 다루며 코드 구조나 구현 방법은 다루지 않는다.

## 게임 정체성

| 항목 | 결정 |
| --- | --- |
| 프로젝트명 | Gulag-project |
| 장르 | 1인칭 무한 생존 슈팅 |
| 플레이 인원 | 1인 |
| 플랫폼 | 데스크톱 웹 브라우저 |

| 목표 생존 시간 | 일반 플레이어 기준 5~8분 |

| 승리 조건 | 없음. 사망 전까지 생존과 고득점을 경쟁 |

## 핵심 경험

플레이어는 매 판 척탄병, 공병, 저격수 중 하나를 선택하고 해당 클래스의 주무기·권총·고유 스킬로 계속 등장하는 적을 처치한다. 적이 떨어뜨린 탄약을 얻으려면 안전한 위치에 머물지 않고 전장 안으로 이동해야 한다. 오래 생존하는 것보다 적극적으로 적을 처치하고 헤드샷과 연속 처치를 이어가는 플레이가 더 높은 점수로 이어진다.

| --- | --- | --- |

## 고정 콘텐츠

| 영역 | 수량 | 구성 |
| --- | ---: | --- |
| 맵 | 1 | 중앙 플랫폼과 외곽 순환 동선이 있는 좁은 아레나 |
| 클래스 | 3 | 척탄병, 공병, 저격수 |
| 일반 무기 | 4 | 권총, 샷건, 라이플, DMR |
| 탄약 종류 | 3 | 권총, 샷건, 라이플. DMR은 라이플 탄약을 공유 |
| 적 | 3 | 자폭형 적, 일반 근거리 적, 원거리 공격 적 |
| 게임 모드 | 1 | 무한 생존 |
| 랭킹 | 1 | 전체 기록 기반 상위 10개와 현재 점수 백분위 |

## 확정 플레이 규칙

- 매 판 시작 전에 클래스 하나를 다시 선택한다.
- 각 클래스는 `1`번 주무기와 `2`번 권총만 사용하며 체력과 이동 속도는 같다.
- `F`는 고유 스킬, 마우스 버튼은 일반 사격 또는 무장한 스킬 발사에 사용한다.
- 탄약은 무기별 `보유 탄약` 하나로 관리하되 DMR은 별도 탄약 없이 라이플 탄약을 공유한다. 탄창과 예비 탄약은 구분하지 않는다.
- 발사 입력 1회마다 현재 무기의 보유 탄약 1발을 소비한다.
- 재장전 입력과 자동 재장전은 제공하지 않는다.
- 적을 처치하면 현재 클래스의 주무기 탄약 또는 권총 탄약이 50%씩 바닥에 떨어진다. 저격수의 주무기 드롭은 라이플 탄약이며 DMR 실루엣으로 표시한다.
- 탄약은 접촉하면 자동으로 획득한다.
- 모든 탄약을 소진해도 별도의 구제 수단은 제공하지 않는다.
- 체력은 마지막 피격 5초 후 최대 체력까지 자동 회복한다.
- 난이도는 적 능력치를 올리지 않고 생성 빈도, 동시 수, 적 조합으로 계속 상승한다.
- 자폭은 플레이어뿐 아니라 주변 적에게도 피해를 준다.
- 플레이어가 유도한 연쇄 폭발 처치는 플레이어의 점수와 콤보에 포함한다.

## 점수와 기록 원칙

- 전투 실력을 생존 시간보다 크게 보상한다.
- 처치 점수는 `B + 헤드샷 30 + 스왑킬 70 + 10 × (C-1) + 스킬 보너스 2B`로 계산한다.
- 무기 종류와 적 종류의 일치는 추가 점수를 주지 않는다.
- 적 기본 점수 `B`는 자폭형 50, 일반 근거리 70, 원거리 100점이고 스킬 처치는 기본 점수의 총 300%를 받는다.
- 콤보 수 `C`는 모든 플레이어 귀속 처치마다 제한 없이 증가하고 5초로 갱신한다.
- 생존 시간은 초당 1점이며 전투 가산 보너스를 적용하지 않는다.
- 결과 화면에서 영문·숫자 2~12자의 닉네임을 입력해 점수를 제출한다.
- 상위 10개 기록에는 닉네임과 점수만 공개한다.
- 닉네임 중복과 같은 플레이어의 복수 기록을 허용한다.
- 개인 최고 기록은 같은 브라우저에 유지한다.
- 온라인 랭킹은 필수 기능이지만 코어 플레이 완성 후 진행하는 후순위 항목이다.

## 공간과 적 이동 원칙

- 중앙 플랫폼은 최초 제출 버전에서 움직이지 않는 고정 구조물이다.
- 맵에는 지상과 상부 교전 지점을 연결하는 명확한 접근 경로가 있어야 한다.
- 세 적 모두 플레이어와 높이가 달라졌을 때 추적하거나 재배치할 수 있어야 한다.
- 향후 중앙 플랫폼이 상하 이동하더라도 적의 전투 역할, 생성 위치, 탄약 접근 동선이 무너지지 않는 공간 구성을 전제로 한다.
- 이동 플랫폼의 실제 구동은 최초 제출 범위에 포함하지 않는다.

## 시각·청각 방향

- 배경은 어두운 전함 내부의 군사 산업 시설이다.
- 검은 강철과 콘크리트를 기본 재질로 사용한다.
- 청백색 작업등으로 공간을 읽게 하고 붉은 경고등은 위험과 적 공격 예고에 제한적으로 사용한다.
- 안개에 의존하지 않고 전투 거리를 선명하게 확인할 수 있어야 한다.
- 적 3종, 클래스 3종과 일반 무기 4종은 실루엣, 색, 동작, 효과음만으로 구분되어야 한다.

## 우선순위

| 우선순위 | 범위 |
| --- | --- |
| 필수 코어 | 클래스 선택, 이동, 카메라, 사격, 고정 2무기, 고유 스킬, 적 3종, 탄약 드롭, 체력, 사망, 재시작 |
| 필수 완성도 | 점수, 콤보, HUD, 결과 화면, 개인 최고 기록, 피격·명중·처치 피드백, 효과음, BGM |

| 제출 준비 | WebGL 안정화, 외부 환경 확인, 썸네일·영상·설명 준비 |

## 제외 범위

- 확정된 DMR 외 추가 무기, 추가 적, 두 번째 맵
- 보스와 별도 클리어 구간
- 런 내부 성장, 스킬 트리, 스킬 레벨, 영구 성장
- 클래스별 패시브와 추가 특수 능력
- 대시와 추가 이동기
- 환경 파괴와 실시간 지형 변경
- 중앙 플랫폼의 실제 상하 이동
- 실시간 멀티플레이와 계정 시스템
- 랭킹 시즌제와 별도 프로필 정보

## 변경 원칙

- 필수 콘텐츠 수를 늘리는 변경은 하지 않는다.
- 새로운 기능을 추가하려면 같은 작업량 이상의 기존 기능을 먼저 제거해야 한다.
- 초기 수치는 플레이테스트 결과에 따라 지정된 범위 안에서 조정한다.
- 범위를 바꾸는 결정은 이 문서를 먼저 수정한 후 관련 문서에 반영한다.
