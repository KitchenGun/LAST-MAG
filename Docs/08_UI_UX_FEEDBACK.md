# UI·UX와 피드백

## 문서 목적

이 문서는 플레이어가 목표, 조작, 전투 상태, 사망 원인, 점수와 기록을 즉시 이해하도록 화면 흐름과 피드백을 정의한다.

## 전체 화면 흐름

`시작 화면·클래스 선택 → 조작 안내 → 게임 HUD → 사망 결과 → 닉네임 제출 → 랭킹 확인 → 클래스 재선택`

시작, 결과, 랭킹 기능은 별도 복잡한 메뉴로 나누지 않고 한 판의 흐름 안에서 빠르게 이동할 수 있게 한다.

## 시작 화면

- 화면 좌측 하단에 현재 빌드를 식별하는 작은 버전 문자열을 항상 표시한다.
- 표시 형식은 `vMAJOR.MINOR.PATCH · WEB-BUILDID`다. 예: `v0.1.0 · WEB-1A2B3C4D`.
- 버전 문자열은 다른 시작 화면 정보보다 낮은 시각 우선순위를 가지며 클래스 선택 화면에서도 유지한다.

### 표시 정보

- 프로젝트명 `Gulag-project`
- 한 줄 목표: 적을 처치하고 탄약을 회수하며 죽을 때까지 높은 점수에 도전
- 척탄병·공병·저격수의 주무기와 고유 스킬 요약
- 현재 선택한 클래스
- 플레이 시작
- 조작 안내
- 기본 음량 상태

### 시작 조건

- 플레이어의 명시적인 시작 입력 후 게임과 오디오를 시작한다.
- 클래스를 선택하기 전에는 플레이를 시작할 수 없다.
- 사망 후 재시작하면 클래스 선택을 초기화하고 시작 화면으로 돌아온다.
- 시작 직후 조작 안내를 짧게 확인할 수 있어야 한다.
- 첫 적이 등장하기 전에 시점과 이동을 확인할 시간을 제공한다.

## 조작 안내

| 행동 | 표시 입력 |
| --- | --- |
| 이동 | `W`, `A`, `S`, `D` |
| 시점 | 마우스 이동 |
| 사격 | 마우스 버튼 |
| 점프 | `Space` |
| 주무기·권총 | `1`, `2` |
| 고유 스킬 | `F` |

조작 안내는 게임 시작 전 확인할 수 있고 첫 플레이 초반에는 HUD에 간단히 다시 표시한다. 전투를 가리는 긴 설명은 사용하지 않는다.

## HUD 정보

| 정보 | 표현 원칙 | 우선순위 |
| --- | --- | ---: |
| 조준점 | 화면 중앙, DMR은 정조준 중에만 기본 조준선 표시 | 최상 |
| 체력 | 현재 체력과 낮은 체력 경고 | 최상 |
| 현재 무기 | 이름과 무기 번호 | 최상 |
| 보유 탄약 | 현재 무기의 남은 수량 하나를 크게 표시 | 최상 |
| 다른 무기 탄약 | 권총 또는 주무기로의 전환 판단이 가능하도록 축약 표시 | 높음 |
| 고유 스킬 | `READY`, `ACTIVE`, `COOLDOWN`과 남은 시간 | 높음 |
| 점수 | 우측 상단의 현재 누적 점수 | 높음 |
| 콤보 | 좌측 중앙의 `COMBO xN`과 남은 5초를 나타내는 탄환 5발 | 높음 |
| 생존 시간 | 경과 시간 | 보통 |

## HUD 배치 원칙

- 조준점과 명중 피드백은 화면 중앙에 둔다. DMR 일반 모드에서는 기본 조준선만 숨기고 HitMarker는 유지한다.
- DMR 정조준 중에는 FOV 45와 검은 가장자리 비네팅을 표시하며 다른 HUD 색상은 유지한다.
- 체력과 피해 경고는 시야를 크게 가리지 않는 화면 가장자리에 둔다.
- 현재 무기와 보유 탄약은 서로 가까이 표시한다.
- 다른 무기의 탄약은 현재 무기보다 작게 표시하되 1·2 번호를 유지한다.
- 스킬 상태는 무기 탄약과 분리하고 `F` 입력과 남은 쿨다운을 함께 표시한다.
- 수류탄·로켓 무장 중에는 별도 `ARMED` 상태를 표시하지 않고 `READY` 아이콘을 강조한다.
- 누적 점수는 우측 상단에 유지하고 콤보는 좌측 중앙에 배치해 적과 조준점을 가리지 않는다.
- 생존 시간은 점수보다 낮은 시각 우선순위를 갖는다.

## 전투 피드백

### 사격과 적중

- 무기마다 총구 효과, 반동 표현, 발사음을 다르게 한다.
- 일반 적중은 짧은 조준점 변화와 적 피격 반응으로 표시한다.
- 헤드샷은 일반 적중과 다른 형태, 소리, 점수 표시를 사용한다.
- DMR은 모든 사격에서 최종 충돌 지점까지 짧은 관통 탄도를 표시한다.
- 적 처치 시 실루엣 해체, 처치음, 점수 증가를 동시에 제공한다.
- 현재 무기의 보유 탄약이 0이면 발사를 막고 탄약 숫자를 짧게 강조한다.

### 피격과 회복

- 피격 방향을 화면 가장자리로 전달한다.
- 낮은 체력에서는 HUD, 화면 가장자리, 경고음을 함께 사용한다.
- 5초 회복 대기 중에는 체력 표시가 회복 시작 전임을 구분한다.
- 회복 시작 시 체력 변화와 짧은 소리로 알린다.
- 재피격으로 회복이 중단되면 즉시 표시한다.

### 자폭 적

- 접근 중인 자폭 적은 실루엣과 반복 경고음으로 구분한다.
- 폭발 예고가 시작되면 색, 형태, 동작, 소리를 함께 강화한다.
- 폭발 범위를 가까운 거리에서 판단할 수 있게 한다.
- 연쇄 폭발 처치는 일반 처치와 다른 점수 피드백을 제공한다.

### 원거리 적

- 조준 시작 방향과 발사 시점을 눈에 띄게 예고한다.
- 원거리 투사체는 어두운 배경과 구분되어야 한다.
- 플레이어가 공격을 피했는지 맞았는지 명확히 느낄 수 있어야 한다.

### 탄약 획득

- 바닥 탄약은 권총, 샷건, 라이플 세 종류로 구분하고 현재 클래스의 두 종류만 등장한다. 저격수의 라이플 탄약에는 DMR 실루엣을 표시한다.
- 접촉 획득 시 해당 무기 번호와 증가량을 짧게 표시한다.
- 보유 탄약이 최대치이면 획득되지 않는 이유를 알아볼 수 있어야 한다.
- 현재 들고 있지 않은 무기 탄약을 얻어도 어떤 탄약인지 알 수 있어야 한다.

## 점수와 콤보 피드백

- 크로스헤어 하단에 흰색 득점 피드를 최대 6줄 표시한다.
- 최신 피드는 상단에 생성하고 기존 항목은 즉시 아래로 정렬하며, 각 항목은 2.25초 유지 후 0.3초 동안 페이드한다.
- Battlefield 3 방식처럼 `ENEMY KILLED  +100`, `HEADSHOT  +30` 등 기본점수와 각 가산점을 짧은 독립 행으로 표시한다.
- 사유는 `ENEMY KILLED`, `HEADSHOT`, `WEAPON MATCH`, `SWAP KILL`, `SKILL KILL`, `CHAIN KILL`, `SKILL CHAIN`, `COMBO xN`을 사용한다.
- 좌측 중앙 콤보는 `COMBO xN`으로 표시하고 카운트 색상을 1콤보 흰색에서 10콤보 붉은색으로 변화시킨 뒤 유지한다.
- 가로 탄환 5발은 실시간 1초마다 오른쪽부터 한 발씩 사라지고 처치 시 5발로 복구된다.
- 탄환은 사용자 제공 Sprite 하나를 5개 `Image`가 공유하며 원본 비율과 투명도를 유지한다. 대체 이미지 생성이나 자동 가공은 하지 않는다.
- 5초가 만료되면 콤보를 0으로 초기화하고 콤보 패널을 숨긴다.
- 생존 시간 점수는 매초 별도 숫자를 띄우지 않고 누적 점수에 조용히 반영한다.

## 사망과 결과 화면

### 즉시 표시

- 최종 점수
- 생존 시간
- 총 처치 수
- 헤드샷 처치 수
- 최고 콤보 수 `MAX COMBO xN`
- 선택 클래스의 주무기와 권총 처치 수
- 선택 클래스의 스킬 기여 처치 수
- 개인 최고 기록
- 개인 최고 기록 갱신 여부

결과 화면의 `LOADOUT KILLS`는 `1` 주무기, `2` 권총, `F` 스킬 순서로 세 행만 표시한다. 척탄병은 `RIFLE / PISTOL / GRENADE`, 공병은 `SHOTGUN / PISTOL / ROCKET`, 저격수는 `DMR / PISTOL / BULLET TIME`을 사용한다. 불릿타임은 전용 아이콘 없이 `F`와 텍스트로 표시한다.
기존 4행 `COMBAT DATA`에서는 `TOTAL KILLS (S/M/R)`에 총 처치와 자폭형·근거리·원거리 처치를 함께 표시하고, `HEADSHOT / CHAIN`에 두 처치 수를 함께 표시한다.

### 기록 제출

- 영문·숫자 2~12자의 닉네임 입력
- 유효하지 않은 문자와 길이에 대한 구체적인 안내
- 제출, 제출 중, 성공, 실패 상태
- 실패 시 현재 입력을 유지한 재시도
- 제출 여부와 관계없이 사용할 수 있는 재시작

### 제출 성공 후

- 상위 10개 순위, 닉네임, 점수
- 현재 점수의 `상위 X%`
- 현재 제출 기록을 구분하는 강조
- 재시작

## 상태 우선순위

동시에 여러 사건이 발생하면 다음 순서로 더 강하게 전달한다.

1. 플레이어 사망
2. 즉시 피해야 하는 자폭·근거리 타격·원거리 공격 예고
3. 낮은 체력과 피격 방향
4. 현재 무기의 탄약 고갈
5. 스킬 준비·활성·쿨다운 전환
6. 헤드샷·처치·콤보
7. 탄약 획득
8. 생존 시간과 일반 점수 증가

## 가독성과 접근성 원칙

- 중요한 정보는 색 하나만으로 구분하지 않고 형태, 움직임, 소리를 함께 사용한다.
- 붉은색은 적 공격과 위험 경고에 우선 사용한다.
- 탄약 3종은 색뿐 아니라 아이콘과 외형을 다르게 한다. 라이플 탄약 아이콘은 척탄병에서 라이플, 저격수에서 DMR 실루엣을 사용한다.
- 반복 섬광과 큰 화면 흔들림은 전투 정보가 가려지지 않는 수준으로 제한한다.
- UI 글자는 어두운 배경과 충분히 대비되어야 한다.
- 사운드가 없어도 공격 예고와 결과를 이해할 수 있어야 한다.

## 성공 기준

- 처음 플레이한 사람이 30초 안에 목표와 기본 입력을 이해한다.
- 시작 전에 클래스를 선택하고 주무기·권총·스킬 역할을 구분할 수 있다.
- 현재 무기와 보유 탄약을 한 번에 확인할 수 있다.
- 자폭, 근거리 타격, 원거리 공격 예고를 화면만 보고 구분할 수 있다.
- 사망 원인을 결과 화면으로 넘어가기 전에 이해한다.
- 닉네임 오류, 제출 성공, 통신 실패를 혼동하지 않는다.
- 결과 화면에서 한 번의 입력으로 클래스 선택 화면으로 돌아갈 수 있다.
