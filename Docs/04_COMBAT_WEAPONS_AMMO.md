# 전투·무기·탄약

## 문서 목적

이 문서는 세 클래스의 고정 로드아웃과 고유 스킬, 권총·샷건·라이플·DMR의 역할, 적 처치 후 탄약이 다시 전투로 이어지는 순환을 정의한다.

## 전투 원칙

- 모든 무기는 화면 중앙을 기준으로 투사체를 발사한다. DMR은 일반 모드에서 조준선을 숨기고 정조준 중에만 표시한다.
- 일반 적중과 헤드샷을 시각·청각적으로 구분한다.
- 적의 공격은 피할 수 있도록 사전에 예고한다.
- 무기 전환은 단순 취향이 아니라 거리, 탄약, 점수 보상에 따른 선택이어야 한다.
- 탄약은 적이 사망한 위치에 떨어지므로 처치가 다음 이동 목표를 만든다.
- 적 종류에 맞는 권장 무기와 현재 거리·탄약에 유리한 무기 사이에 선택이 발생해야 한다.

## 무기 요약

| 무기 | 역할 | 유효 거리 | 점수 특성 | 주요 약점 |
| --- | --- | --- | --- | --- |
| 권총 | 정밀한 단발 사격 | 중·장거리 | 자폭형 적 권장 무기 | 다수의 근접 적 처리 속도가 낮음 |
| 샷건 | 근거리 중심 순간 화력 | 근·중거리 | 일반 근거리 적 권장 무기 | 장거리에서 효율이 크게 감소 |
| 라이플 | 안정적인 연속 사격 | 중거리 | 원거리 적 권장 무기 | 탄약 소비가 빠름 |
| DMR | 관통 정밀 반자동 사격 | 장거리 | 라이플 계열로 원거리 적 권장 무기 | 빠른 조준과 탄도 판단이 필요 |

## 권총

### 플레이 역할

정확한 조준으로 적을 적은 탄약에 처치하고 헤드샷을 노리는 무기다. 자폭형 적의 권장 무기이며 접근하기 전에 약점을 맞히는 데 유리하다.

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 시작 보유 탄약 | 15발 | 15발 |
| 보유 탄약 최대치 | 15발 | 15발 |
| 발당 피해 | 30 | 25~35 |
| 초당 발사 수 | 6.75회(405 RPM) | 5~8회 |
| 헤드샷 배율 | ×1.5 (GameplayScene 실제값) | 고정 |

- 자폭형 적도 다른 적과 동일하게 헤드샷 처치 시 +30점을 받는다.
- GameplayScene은 권총 확산 `1°`와 헤드샷 배율 `×1.5`를 PF_Player 기본값(`0.35°`, `×2`)보다 우선한다.
- 빠른 연타보다 조준 회복과 명중 확인이 중요하게 느껴져야 한다.
- 자폭 적을 안전한 거리에서 제거할 수 있지만 빗나가면 접근을 허용한다.

## 샷건

### 플레이 역할

접근한 일반 근거리 적을 강한 순간 화력으로 해결하는 권장 무기다.

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 시작 보유 탄약 | 8발 | 8발 |
| 보유 탄약 최대치 | 8발 | 8발 |
| 한 발의 투사체 수 | 8개 | 6~10개 |
| 투사체당 피해 | 12 | 10~14 |
| 초당 발사 수 | 1.1회(66 RPM) | 0.8~1.3회 |
| 헤드샷 배율 | ×2 | 고정 |

- 여러 투사체가 가까운 거리에서 맞을수록 높은 피해를 준다.
- 5° 산탄 분포로 8~12m에서도 복수 투사체 적중을 기대할 수 있지만 근거리에서 가장 강하다.
- 각 펠릿은 서로 다른 적 최대 2명을 관통하며, 두 번째 적도 피해 감쇠 없이 동일한 펠릿 피해를 받는다. 벽·바닥·기타 비적 충돌체에서 즉시 멈춘다.
- 일반 근거리 적도 다른 적과 동일하게 헤드샷 처치 시 +30점을 받는다.
- 자폭 적에게 너무 늦게 접근하면 처치와 동시에 폭발 피해를 받을 수 있어야 한다.
- 원거리 적에게 접근할 수 있다면 높은 위험을 감수한 빠른 처치 수단이 된다.

## 라이플

### 플레이 역할

다수의 적을 안정적으로 약화하고 콤보를 이어가는 무기다. 원거리 적의 권장 무기이며 가장 넓은 상황에서 꾸준히 사용할 수 있다.

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 시작 보유 탄약 | 50발 | 50발 |
| 보유 탄약 최대치 | 50발 | 50발 |
| 발당 피해 | 15 | 12~18 |
| 초당 발사 수 | 11회(660 RPM) | 9~12회 |
| 헤드샷 배율 | ×2 | 고정 |

- 이동하는 자폭 적과 재배치하는 원거리 적에게 대응하기 쉽다.
- 연속 사격은 탄약을 빠르게 소비하므로 다음 무기 전환을 앞당긴다.
- 원거리 적도 다른 적과 동일하게 헤드샷 처치 시 +30점을 받는다.
- 라이플만 사용해도 항상 탄약이 유지된다면 드롭 확률과 소비량을 먼저 조정한다.

## DMR

### 플레이 역할

저격수의 주무기로 적과 벽을 관통해 정렬된 표적을 처리한다. 라이플 계열로 취급해 원거리 적 권장 무기 조건을 충족한다.

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 시작 DMR 보유 탄약 | 15발 | 15발 |
| DMR 보유 탄약 최대치 | 15발 | 15발 |
| 최초 피해 | 60 | 40~70 |
| 초당 발사 수 | 5.25회(315 RPM) | 3~6회 |
| 처리 충돌체 | 최대 3개 | 고정 |
| 헤드샷 배율 | ×2 | 고정 |

- 반자동이며 발사 입력 1회마다 한 발을 소비한다.
- 최초 명중을 포함해 최대 3개 충돌체를 처리하고 적과 벽 모두 한 단계를 소비한다.
- 코드 기본 피해는 `60 → 40 → 20`이지만 GameplayScene 직렬화 오버라이드가 실제 런타임을 `60 → 60 → 60`으로 만든다. 세 번째 충돌에서 탄도가 끝난다.
- 각 적의 머리 판정에는 해당 단계 피해의 2배를 적용한다.
- 모든 사격에 총구부터 최종 충돌 지점까지 짧은 탄도 파티클을 표시한다.
- DMR은 저격수의 별도 보유 탄약 슬롯에서 1발을 소비한다. 라이플과 파란색·드롭 규칙을 공유하지만 런타임 탄약 풀은 분리되어 있다.
- 우클릭으로 정조준을 토글하며 카메라 FOV를 `90↔45`로 0.12초 동안 전환한다.
- 정조준 중 마우스 감도는 50%이며 검은 화면 가장자리 비네팅과 중앙 조준선을 표시한다.
- 일반 모드 사격은 허용하지만 조준선은 숨긴다. 무기 교체·커서 해제·사망 시 정조준을 취소한다.

## 클래스와 고유 스킬

모든 클래스는 같은 체력과 이동 속도를 사용하고 `1`번 주무기, `2`번 권총, `F` 고유 스킬만 가진다. 패시브, 스킬 레벨과 별도 스킬 탄약은 없다.

| 클래스 | 주무기 | 스킬 | 공격 규칙 | 효과 종료 후 쿨다운 |
| --- | --- | --- | --- | ---: |
| 척탄병 | 라이플 50발 | 수류탄 | 12m/s 포물선 투척, 4.5초 후부터 1초 간격으로 90 피해·반경 5m 폭발 3회 | 10초 |
| 공병 | 샷건 8발 | 로켓 런처 | 25m/s 직선 비행, 충돌 즉시 또는 5초 후 150 피해·반경 4m 폭발 | 12초 (GameplayScene 실제값) |
| 저격수 | DMR 15발 | 불릿타임 | 5초 동안 적·적 투사체·적 생성 등 세계 속도를 35%로 감소 | 20초 |

- 척탄병과 공병은 `F`로 스킬을 무장하고 마우스 버튼으로 발사한다.
- 무장 중 `F` 재입력은 무시하고 무기 전환으로만 비용 없이 취소한다.
- 수류탄은 발사 직후 이전 무기로 돌아간다. 로켓 런처는 발사 후 0.28초 회복 대기와 0.42초 복귀를 완료한 뒤 이전 무기로 돌아간다.
- 수류탄은 첫 폭발 위치에 고정되어 메시를 유지하고 `4.5/5.5/6.5초`에 폭발한 뒤 세 번째 폭발 후 사라진다.
- 수류탄은 공중에서 Linear/Angular Damping `0/0.05`를 유지하고, 적이 아닌 지면 접점 Normal Y `0.55` 이상에 처음 닿은 뒤 `2.5/8.0`으로 높여 짧게 구른다. 벽·적 측면 충돌은 이 감쇠를 적용하지 않는다.
- 같은 적과 플레이어가 범위에 남아 있으면 매 폭발마다 각각 90·45 피해를 다시 받으며, 수류탄 쿨다운은 세 번째 폭발 후 시작한다.
- 로켓 런처 모델은 플레이어 카메라에 남고 별도 투사체만 비행한다. 최종 투사체 아트 전까지 초록색 발광 캡슐을 임시로 사용한다.
- 폭발이 끝난 시점부터 스킬 쿨다운을 계산한다.
- 수류탄과 로켓은 범위 안에 고정 피해를 주고 거리와 벽의 영향을 받지 않는다.
- 자기 피해는 수류탄 45, 로켓 75로 적 대상 피해의 절반이다.
- 저격수는 `F` 입력 즉시 불릿타임을 활성화하고 종료 뒤 쿨다운을 시작한다. 불릿타임 중 헤드샷 처치 1회마다 실시간 지속 시간이 `0.5초` 연장되며, 다음 연장부터 필요한 헤드샷 처치 수가 1씩 증가한다(1회, 2회, 3회 …).
- 불릿타임 중 플레이어 입력·이동·점프·중력은 실시간이고, 적·투사체·스폰 등 세계와 무기 모델 반동·총구 화염·연기·탄도 파티클·배경음악은 35% 속도를 따른다. 조준·사격 속도, Aim Recoil·Fire Impulse, HUD, 체력 회복, 생존 점수와 콤보 타이머는 실시간을 유지한다.
- 모든 스킬은 `준비·활성·쿨다운` 세 상태만 사용한다.

## 공통 헤드샷 규칙

- 샷건·라이플·DMR은 머리 판정에 ×2를 적용하고, 권총은 GameplayScene에서 ×1.5를 적용한다.
- 샷건은 머리에 적중한 투사체에만 2배 피해를 적용하고 몸통 투사체와 합산한다.
- 마지막 공격이 머리 판정으로 적을 사망시킨 경우만 헤드샷 처치로 처리한다.
- 헤드샷 처치는 적 종류와 무관하게 +30점을 받는다.
- 무기 종류와 적 종류의 일치는 추가 점수를 주지 않는다.
- 한 번의 샷건 사격에서 여러 투사체가 머리에 적중해도 처치 한 번에 헤드샷 보너스 한 번만 적용한다.

### 체력별 몸통 처치 요구량

| 무기 | 자폭형 1 | 근접형 75 | 원거리형 90 |
| --- | ---: | ---: | ---: |
| 권총 | 1발 | 3발 | 3발 |
| 샷건 | 1펠릿 | 7펠릿 | 8펠릿 |
| 라이플 | 1발 | 5발 | 6발 |
| DMR 최초 명중 | 1발 | 2발 | 2발 |

## 발사와 무기 전환

- 무기마다 탄창과 예비 탄약을 구분하지 않고 보유 탄약 하나만 관리한다.
- 권총과 라이플 계열은 투사체 1발마다, 샷건은 한 번의 산탄 발사마다, DMR은 별도 DMR 슬롯에서 보유 탄약 1발을 소비한다.
- 재장전 입력과 자동 재장전은 제공하지 않는다.
- 클래스의 두 무기를 전환해도 각 무기의 보유 탄약을 유지한다.
- 현재 무기의 보유 탄약이 0이면 자동 전환하지 않고 HUD로 알리며 플레이어가 직접 다른 무기를 선택한다.

## 탄약 드롭

### 종류 결정

| 드롭 종류 | 초기 확률 | 조정 원칙 |
| --- | ---: | --- |
| 현재 클래스 주무기 탄약 | 60% (생성된 상자 중) | 권총보다 자주 등장하도록 유지 |
| 권총 탄약 | 40% (생성된 상자 중) | 주무기와의 보급 격차를 완화 |

모든 적의 전체 탄약 드롭 확률은 50%이며, 드롭이 발생한 경우에만 주무기와 권총을 60:40으로 결정한다. 따라서 처치당 최종 확률은 주무기 30%, 권총 20%, 미드롭 50%다. 사용할 수 없는 다른 클래스 무기의 탄약은 등장하지 않는다. 저격수의 주무기 드롭은 파란색 DMR 탄약으로 표시한다. 자연 자폭도 같은 60:40으로 탄약 종류만 결정하며 점수와 콤보를 지급하지 않는다.

### 드롭량

| 탄약 | 초기 드롭량 | 조정 범위 |
| --- | ---: | ---: |
| 권총 | 5발 | 3~9발 |
| 샷건 | 3발 | 1~4발 |
| 라이플 | 20발 | 10~25발 |
| DMR | 5발 | 2~6발 |

- 탄약 상자 하나는 무기별 고정량을 지급한다. 초기값은 권총 `15→5`, 샷건 `8→3`, 라이플 `50→20`, DMR `15→5`다.
- DMR은 라이플 탄약 종류와 파란색을 공유하지만, 저격수의 최대 보유 탄약 15발을 기준으로 5발을 지급하고 DMR 실루엣으로 표시한다.
- 모든 적은 사망 시 50% 확률로 탄약 하나를 떨어뜨린다.
- 탄약은 적이 사망한 위치의 바닥에서 획득할 수 있어야 한다.
- 플레이어가 접촉하면 해당 무기의 보유 탄약에 추가한다.
- 보유 탄약이 최대치라면 획득하지 않고 바닥에 남긴다.
- 최대치까지 일부만 받을 수 있다면 필요한 양만 받고 나머지는 소멸한다.
- 바닥 탄약은 탄약 종류별 색을 사용한다. 라이플 탄약은 척탄병에게 라이플 실루엣, 저격수에게 DMR 실루엣으로 표시한다.
- 활성 탄약 상자는 최대 30개까지 유지한다.
- 30개가 활성화된 상태에서 새 탄약이 떨어지면 가장 오래된 상자를 새 위치에 재사용한다.
- 탄약 상자에는 시간에 따른 자동 소멸을 적용하지 않는다.

## 탄약 고갈

- 보유 탄약이 0인 무기는 발사할 수 없다.
- 모든 무기의 탄약이 0이 되어도 게임은 계속 진행한다.
- 비상 탄약, 자동 충전, 근접 공격은 제공하지 않는다.
- 기존에 바닥에 떨어진 탄약을 회수하지 못하면 공격 수단 없이 회피하다 사망한다.

## 조정 우선순위

| 문제 | 먼저 조정할 항목 |
| --- | --- |
| 한 무기만 계속 사용됨 | 두 무기의 드롭량, 시작 탄약, 발당 효율 |
| 탄약이 너무 자주 완전 고갈됨 | 드롭량, 시작 보유 탄약, 적 체력 |
| 탄약이 항상 최대치임 | 드롭량, 보유 탄약 최대치, 소비 속도 |
| 한 무기가 모든 적의 점수 전략을 지배함 | 스왑킬 +70점, 발사 속도, 피해, 탄약 효율 |
| 클래스가 특정 적에게 지나치게 불리함 | 적 조합, 스킬 쿨다운, 무기 성능 |
| 헤드샷 보상이 과도함 | 적 기본 점수와 헤드샷 +30점 |

## 반동 구현 계약

반동 계산은 `FirstPersonController`가 실제 조준값과 발사 판정을 소유하고, `WeaponViewmodelController`가 무기 모델 스프링을, `PlayerSkillController`가 스킬 투사체 반동을 소유한다. `GameplayScene` 직렬화 값이 `PF_Player` 기본값보다 우선하며, 실제 조준선 Ray에는 Viewmodel·Camera Rock을 포함하지 않는다.

| 무기 | Aim Pitch/Yaw | Random | Soft/Hard Cap | 복귀 | 연속 잔류 판정 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 권총 | 2.2° / 0.35° | ±10% | 3.5° / 4.5° | 0.12초 | 0.24초, 20% |
| 라이플 | 2.3° / 0.32° | ±12% | 6° / 7° | 0.12초 | 0.32초, 35% |
| DMR | 3.2° / 0.45° | ±10% | 4.8° / 6° | 0.20초 | 0.42초, 25% |
| 샷건 | 4.6° / 0.85° | ±15% | 4.5° / 5.5° | 0.29초 | 없음 |
| 로켓 | 5.6° / 1.1° | ±15% | 5.5° / 6.5° | 0.42초 | 없음 |

- Yaw는 기준값의 75~100%로, 실제 Pitch의 40% 이하로 제한한다. Soft Cap 접근 시 추가 Pitch는 25%까지 줄이고 Hard Cap을 넘지 않는다.
- 상승은 Ease-Out Quad, 복귀는 Ease-Out Cubic이다. 같은 무기 연속 사격만 마지막 복귀 시작값의 권총 20%·라이플 35%·DMR 25%를 기본 조준각에 남긴다.
- Camera Rock은 권총 `0.35°/0.05°/0.12°`, 라이플 `0.25°/0.05°/0.12°`, DMR `0.50°/0.10°/0.18°`, 샷건 `0.75°/0.15°/0.28°`, 로켓 `1.00°/0.20°/0.35°`(Pitch/Yaw/Roll)이며 발사 Ray에는 포함하지 않는다.
- 발사 입력은 1/120초 단위로 최대 8회까지 처리하고, 불릿타임에서는 플레이어 조준·사격을 실시간으로 유지한다.
- 회귀 검증은 단발 복귀, 연속 잔류 시간, Soft/Hard Cap, 무기 전환, 불릿타임 시간 배율과 화면 중심 판정을 확인한다.
