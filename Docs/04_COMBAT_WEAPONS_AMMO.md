# 전투·무기·탄약

## 문서 목적

이 문서는 공통 전투 규칙, 권총·샷건·라이플의 역할, 적 처치 후 탄약이 다시 전투로 이어지는 순환을 정의한다.

## 전투 원칙

- 모든 무기는 화면 중앙 조준점을 기준으로 투사체를 발사한다.
- 일반 적중과 헤드샷을 시각·청각적으로 구분한다.
- 적의 공격은 피할 수 있도록 사전에 예고한다.
- 무기 전환은 단순 취향이 아니라 거리, 탄약, 점수 보상에 따른 선택이어야 한다.
- 탄약은 적이 사망한 위치에 떨어지므로 처치가 다음 이동 목표를 만든다.
- 안전한 라이플과 높은 점수 기회를 주는 권총·샷건 사이에 선택이 발생해야 한다.

## 무기 요약

| 무기 | 역할 | 유효 거리 | 점수 특성 | 주요 약점 |
| --- | --- | --- | --- | --- |
| 권총 | 정밀한 단발 사격 | 중·장거리 | 헤드샷 추가 보상 | 다수의 근접 적 처리 속도가 낮음 |
| 샷건 | 근거리 순간 화력 | 근거리 | 근거리 처치 추가 보상 | 거리 증가 시 효율이 크게 감소 |
| 라이플 | 안정적인 연속 사격 | 중거리 | 별도 무기 보너스 없음 | 탄약 소비가 빠르고 최고 득점 잠재력이 낮음 |

## 권총

### 플레이 역할

정확한 조준으로 적을 적은 탄약에 처치하고 헤드샷 점수를 노리는 무기다. 원거리 적을 공격하거나 자폭 적이 접근하기 전에 약점을 맞히는 데 유리하다.

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 시작 보유 탄약 | 15발 | 15발 |
| 보유 탄약 최대치 | 15발 | 15발 |
| 발당 피해 | 30 | 25~35 |
| 초당 발사 수 | 3회 | 2.5~4회 |

- 일반 헤드샷 보상에 권총 전용 헤드샷 보너스가 추가된다.
- 빠른 연타보다 조준 회복과 명중 확인이 중요하게 느껴져야 한다.
- 자폭 적을 안전한 거리에서 제거할 수 있지만 빗나가면 접근을 허용한다.

## 샷건

### 플레이 역할

자폭 적에게 접근을 허용한 상황을 강한 순간 화력으로 해결하거나, 위험을 감수하고 근거리 처치 점수를 노리는 무기다.

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 시작 보유 탄약 | 6발 | 6발 |
| 보유 탄약 최대치 | 6발 | 6발 |
| 한 발의 투사체 수 | 8개 | 6~10개 |
| 투사체당 피해 | 12 | 10~14 |
| 초당 발사 수 | 1회 | 0.8~1.3회 |
| 근거리 보너스 기준 | 6m 이내 | 4~8m |

- 여러 투사체가 가까운 거리에서 맞을수록 높은 피해를 준다.
- 근거리 기준 안에서 적을 처치하면 샷건 전용 점수 보너스를 얻는다.
- 자폭 적에게 너무 늦게 접근하면 처치와 동시에 폭발 피해를 받을 수 있어야 한다.
- 원거리 적에게 접근할 수 있다면 높은 위험을 감수한 빠른 처치 수단이 된다.

## 라이플

### 플레이 역할

다수의 적을 안정적으로 약화하고 콤보를 이어가는 무기다. 점수 특화 행동은 없지만 가장 넓은 상황에서 꾸준히 사용할 수 있다.

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 시작 보유 탄약 | 30발 | 30발 |
| 보유 탄약 최대치 | 30발 | 30발 |
| 발당 피해 | 15 | 12~18 |
| 초당 발사 수 | 8회 | 7~10회 |

- 이동하는 자폭 적과 재배치하는 원거리 적에게 대응하기 쉽다.
- 연속 사격은 탄약을 빠르게 소비하므로 다음 무기 전환을 앞당긴다.
- 헤드샷 기본 보상은 받지만 라이플 전용 추가 보상은 없다.
- 라이플만 사용해도 항상 탄약이 유지된다면 드롭 확률과 소비량을 먼저 조정한다.

## 공통 헤드샷 규칙

- 머리 부위에 적중한 공격은 헤드샷으로 처리한다.
- 헤드샷으로 적을 처치하면 기본 처치 점수의 50%를 추가한다.
- 권총 헤드샷 처치는 기본 처치 점수의 50%를 다시 추가해 총 100%의 헤드샷 관련 보너스를 얻는다.
- 샷건과 라이플은 공통 헤드샷 보너스만 적용한다.
- 한 번의 샷건 사격에서 여러 투사체가 머리에 적중해도 처치 한 번에 헤드샷 보너스 한 번만 적용한다.

## 발사와 무기 전환

- 무기마다 탄창과 예비 탄약을 구분하지 않고 보유 탄약 하나만 관리한다.
- 권총과 라이플은 투사체 1발마다, 샷건은 한 번의 산탄 발사마다 보유 탄약 1발을 소비한다.
- 재장전 입력과 자동 재장전은 제공하지 않는다.
- 무기를 전환해도 각 무기의 보유 탄약을 유지한다.
- 현재 무기의 보유 탄약이 0이면 자동 전환하지 않고 HUD로 알리며 플레이어가 직접 다른 무기를 선택한다.

## 탄약 드롭

### 종류 결정

| 드롭 종류 | 초기 확률 | 조정 원칙 |
| --- | ---: | --- |
| 처치에 사용한 무기 탄약 | 20% | 10~30% 범위에서 조정 |
| 사용하지 않은 첫 번째 무기 탄약 | 40% | 남은 확률을 두 무기가 동일하게 나눔 |
| 사용하지 않은 두 번째 무기 탄약 | 40% | 남은 확률을 두 무기가 동일하게 나눔 |

처치 무기 탄약 확률을 바꾸면 다른 두 무기의 확률은 서로 같게 유지한다. 예를 들어 처치 무기 탄약이 30%라면 다른 두 무기는 각각 35%다.

자폭 적이 플레이어 접근으로 스스로 폭발한 경우에는 폭발 순간 플레이어가 장착한 무기를 처치 무기로 간주한다.

### 드롭량

| 탄약 | 초기 드롭량 | 조정 범위 |
| --- | ---: | ---: |
| 권총 | 12발 | 6~18발 |
| 샷건 | 6발 | 3~9발 |
| 라이플 | 30발 | 15~45발 |

- 모든 적은 사망 시 탄약 하나를 떨어뜨린다.
- 탄약은 적이 사망한 위치의 바닥에서 획득할 수 있어야 한다.
- 플레이어가 접촉하면 해당 무기의 보유 탄약에 추가한다.
- 보유 탄약이 최대치라면 획득하지 않고 바닥에 남긴다.
- 최대치까지 일부만 받을 수 있다면 필요한 양만 받고 나머지는 소멸한다.
- 바닥 탄약은 무기별 색과 형태를 달리한다.

## 탄약 고갈

- 보유 탄약이 0인 무기는 발사할 수 없다.
- 모든 무기의 탄약이 0이 되어도 게임은 계속 진행한다.
- 비상 탄약, 자동 충전, 근접 공격은 제공하지 않는다.
- 기존에 바닥에 떨어진 탄약을 회수하지 못하면 공격 수단 없이 회피하다 사망한다.

## 조정 우선순위

| 문제 | 먼저 조정할 항목 |
| --- | --- |
| 한 무기만 계속 사용됨 | 해당 무기 드롭 확률, 시작 탄약, 발당 효율 |
| 탄약이 너무 자주 완전 고갈됨 | 드롭량, 시작 보유 탄약, 적 체력 |
| 탄약이 항상 최대치임 | 드롭량, 보유 탄약 최대치, 소비 속도 |
| 권총이 점수와 안정성을 모두 지배함 | 발사 속도, 피해, 권총 헤드샷 추가 보너스 |
| 샷건 보너스가 위험하지 않음 | 근거리 기준, 자폭 적 폭발 예고와 범위 |
| 라이플이 점수 경쟁에서도 최선임 | 탄약 소비, 발당 피해, 콤보 보상과 다른 무기 보너스 |
