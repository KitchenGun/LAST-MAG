# 적과 난이도

## 문서 목적

이 문서는 자폭형 적, 일반 근거리 적, 원거리 공격 적의 역할, 공격 예고, 상호작용, 시간에 따른 연속 난이도 상승을 정의한다.

## 공통 원칙

- 적은 자폭형, 일반 근거리, 원거리의 세 종류만 사용한다.
- 적의 체력과 공격력은 시간이 지나도 상승하지 않는다.
- 난이도는 생성 간격, 동시 수, 근거리 위협·원거리 비율로 상승한다.
- 모든 공격은 플레이어가 보고 반응할 수 있도록 예고한다.
- 적은 탄약을 남기므로 처치 위치가 다음 이동 목표가 된다.
- 세 적 모두 지상과 상부 교전 지점 사이의 높이 변화에 대응할 수 있어야 한다.
- 향후 중앙 플랫폼이 움직여도 적의 역할이 바뀌지 않아야 한다.

## 자폭형 적

### 역할

플레이어에게 직접 접근해 이동 공간을 줄이고 안전한 조준을 방해한다. 단독으로는 단순하지만 여러 마리가 원거리 적과 함께 등장하면 즉각적인 우선순위 판단을 요구한다.

### 행동 흐름

1. 등장 후 플레이어 위치를 향해 이동한다.
2. 지상과 상부 경로 중 도달 가능한 경로를 선택한다.
3. 폭발 범위에 들어오면 이동을 멈추고 폭발을 예고한다.
4. 예고 시간이 끝나면 자폭한다.
5. 사격이나 다른 폭발로 처치되더라도 0.2초 뒤 폭발한다.
6. 폭발은 플레이어와 범위 안의 다른 적에게 피해를 준다.

### 초기 수치

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 체력 | 60 | 45~75 |
| 폭발 피해 | 60 | 40~70 |
| 폭발 범위 | 4m | 3~5m |
| 폭발 예고 | 0.8초 | 0.6~1.2초 |
| 기본 처치 점수 | 100점 | 80~120점 |

### 전투 규칙

- 플레이어는 접근 전에 사격으로 제거하거나 다른 적 근처까지 유도할 수 있다.
- 플레이어가 직접 처치했거나 플레이어 귀속 연쇄 폭발로 쓰러진 자폭형의 폭발 피해로 다른 적의 체력이 0이 되면 플레이어 귀속 연쇄 처치로 인정한다.
- 폭발 피해로 다른 자폭 적이 쓰러지면 해당 적도 폭발할 수 있다.
- 예고 전 사격 처치를 포함한 모든 사망은 0.2초 뒤 폭발한다.
- 플레이어 귀속 연쇄 처치는 적 종류와 무관하게 ×0.7 행동 계수로 점수와 콤보에 포함한다.
- 자연 자폭과 비귀속 연쇄 폭발은 점수와 콤보를 지급하지 않는다.
- 폭발 범위와 남은 예고 시간은 가까운 거리에서 명확히 알아볼 수 있어야 한다.
- 화면 밖에서 갑자기 접근해 예고 없이 폭발해서는 안 된다.

## 일반 근거리 적

### 역할

플레이어를 빠르게 추적하고 반복 타격해 조준과 회복 공간을 줄인다. 자폭형과 달리 한 번의 폭발로 사라지지 않는 지속적인 근거리 위협이다.

### 행동 흐름

1. 플레이어에게 도달 가능한 경로로 추적한다.
2. 공격 범위에 들어오면 멈추고 내려찍기 공격을 0.45초간 예고한다.
3. 예고 시작 시 공격 방향을 고정한다.
4. 타격 순간 플레이어가 범위를 벗어났다면 공격은 빗나간다.
5. 다음 공격 가능 시점까지 기다린 뒤 같은 흐름을 반복한다.

### 초기 수치

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 체력 | 75 | 60~90 |
| 공격 피해 | 15 | 10~20 |
| 이동 속도 | 4m/s | 3~5m/s |
| 공격 범위 | 1.8m | 1.5~2.2m |
| 공격 예고 | 0.45초 | 0.35~0.65초 |
| 공격 간격 | 1.2초 | 1.0~1.6초 |
| 기본 처치 점수 | 100점 | 80~120점 |

### 전투 규칙

- 이동 중에는 공격하지 않고 범위에 들어온 뒤 예고한다.
- 예고가 시작된 뒤에는 공격 방향을 바꾸지 않는다.
- 플레이어는 측면 이동으로 내려찍기를 피할 수 있어야 한다.
- 자폭형 적의 폭발 피해를 받는다.
- 피해를 받으면 0.2초 피격 동작을 재생하고, 체력이 0이 되면 약 1.2초 사망 동작 후 모델을 제거한다.

## 원거리 공격 적

### 역할

안전한 이동 경로와 회복 시간을 방해한다. 플레이어가 자폭 적에게만 집중하지 못하게 만들고 중앙과 외곽 사이의 위치 변경을 유도한다.

### 행동 흐름

1. 등장 후 플레이어를 공격할 수 있는 중거리 위치로 이동한다.
2. 플레이어와 높이가 다르면 연결 경로를 사용해 재배치한다.
3. 공격 위치에 도달하면 이동을 멈춘다.
4. 조준 방향과 발사 시점을 예고한다.
5. 플레이어가 보고 피할 수 있는 원거리 공격을 발사한다.
6. 거리와 시야가 유효한 동안 같은 위치에서 공격을 반복한다.
7. 시야가 막히거나 선호 거리를 벗어날 때만 다른 사격 위치로 이동한다.

### 초기 수치

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 체력 | 90 | 70~110 |
| 공격 피해 | 15 | 10~20 |
| 공격 예고 | 0.7초 | 0.5~1.0초 |
| 공격 간격 | 2.2초 | 1.8~3.0초 |
| 선호 거리 | 10~18m | 8~22m |
| 기본 처치 점수 | 150점 | 120~180점 |

### 전투 규칙

- 이동 중에는 공격하지 않고 정지한 뒤 예고하고 사격한다.
- 플레이어가 너무 가까워지면 거리를 다시 확보한다.
- 발사 가능한 위치에서는 2.2초마다 계속 공격한다.
- 사격 위치를 바꿀 때 중앙과 상부 경로를 모두 사용할 수 있다.
- 자폭 적의 폭발 피해를 받으며, 플레이어 귀속 폭발로 사망하면 연쇄 처치로 인정한다.
- 구조물 뒤에서 플레이어를 공격할 수 없는 상태로 오래 머물러서는 안 된다.
- 피해를 받으면 0.2초 피격 동작을 재생하고, 체력이 0이 되면 약 1.2초 사망 동작 후 모델을 제거한다.

## 적 조합의 역할

| 조합 | 플레이어에게 요구하는 판단 |
| --- | --- |
| 자폭 적 다수 | 가까운 위협 제거, 연쇄 폭발 유도, 후퇴 경로 확보 |
| 일반 근거리 적 다수 | 방향이 고정된 공격 회피, 지속적인 거리 확보 |
| 원거리 적 다수 | 공격 예고 확인, 엄폐와 이동, 정밀 사격 |
| 근거리 위협 + 원거리 적 | 가까운 적과 장거리 압박 사이의 우선순위 결정 |
| 자폭형·일반 근거리·원거리 적 | 자폭을 다른 적 근처로 유도할지 즉시 제거할지 선택 |

## 생성 원칙

- 적은 전장 외곽의 여러 진입 지점에서 등장한다.
- 등장 지점은 문, 통로, 경고등처럼 공간 안에서 이해할 수 있어야 한다.
- 플레이어 바로 옆이나 즉시 폭발 범위 안에는 생성하지 않는다.
- 적은 등장 직후 공격하지 않고 위치와 종류를 확인할 시간을 제공한다.
- 같은 진입 지점에서만 연속 생성해 한 방향을 막지 않는다.
- 탄약이 접근할 수 없는 공간에 떨어지지 않도록 적의 활동 영역을 제한한다.

## 연속 난이도 곡선

난이도 변화는 화면에 웨이브로 표시하지 않는다. 아래 값 사이를 시간에 따라 부드럽게 연결한다.

| 경과 시간 | 동시 적 목표 | 생성 간격 | 근거리 위협:원거리 비율 | 의도 |
| --- | ---: | ---: | ---: | --- |
| 0~1분 | 3~5명 | 3.0~2.4초 | 80:20 | 기본 대응 학습 |
| 1~3분 | 5~10명 | 2.4~1.6초 | 70:30 | 세 적 조합 시작 |
| 3~5분 | 8~12명 | 1.6~1.1초 | 60:40 | 탄약과 위치 압박 결합 |
| 5~8분 | 14~20명 | 1.1~0.7초 | 55:45 | 목표 생존 시간의 최고 압박 |
| 8분 이후 | 최대 20명 | 최저 0.7초 | 50:50 | 능력치 상승 없이 조합 압박 유지 |

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 최대 동시 적 | 20명 | 16~24명 |
| 최소 생성 간격 | 0.7초 | 0.6~1.0초 |
| 원거리 적 최대 비율 | 50% | 40~60% |

- 최대 동시 적에 도달하면 기존 적이 줄어들 때까지 추가 생성을 기다린다.
- 동시 적 수가 시간대의 목표보다 낮으면 생성 압박을 높이되 최소 생성 간격보다 짧아지지 않는다.
- 적 체력, 피해, 이동 속도, 공격 속도는 시간에 따라 자동 상승하지 않는다.
- 8분 이후에는 수치를 무한히 높이지 않고 최대 동시 수 안에서 조합과 생성 방향으로 긴장을 유지한다.
- 근거리 위협은 자폭형과 일반 근거리 적을 합친 비율이며, 둘 사이의 세부 생성 비율은 스포너 단계에서 결정한다.

## 높이 변화 대응

- 초기 중앙 플랫폼은 고정되어 있다.
- 모든 주요 교전 높이는 플랫폼 이동 없이도 두 개 이상의 접근 경로로 연결한다.
- 자폭 적은 플레이어와 같은 높이로 이동해 폭발을 시도한다.
- 일반 근거리 적은 플레이어와 같은 높이로 이동해 타격을 시도한다.
- 원거리 적은 같은 높이로 이동하거나 유효한 사격 위치로 재배치한다.
- 향후 플랫폼이 상하 이동하더라도 적이 영구적으로 고립되거나 플레이어에게 도달할 수 없는 상태가 되면 안 된다.

## 불공정 상황 방지

- 자폭 예고가 다른 효과에 가려지지 않아야 한다.
- 원거리 공격 예고와 탄약 색을 같은 방식으로 표현하지 않는다.
- 동시에 여러 원거리 적이 공격할 때도 피할 방향이 최소 하나는 남아야 한다.
- 적 생성과 자폭 폭발이 겹쳐 즉시 피해를 주지 않아야 한다.
- 플레이어가 접근할 수 없는 곳에서 원거리 적이 계속 공격하지 않아야 한다.
