# 점수·콤보·랭킹

## 문서 목적

이 문서는 전투 행동을 점수로 변환하는 규칙, 연속 처치 보상, 개인 최고 기록, 온라인 상위 10개와 현재 점수 백분위를 정의한다.

## 점수 설계 원칙

- 전투 실력이 생존 시간보다 큰 점수 차이를 만든다.
- 위험하거나 정밀한 행동은 안전한 공격보다 더 높은 점수를 준다.
- 콤보는 적을 빠르게 연속 처치하도록 유도한다.
- 점수 규칙은 결과 화면만 보아도 어떤 행동이 보상됐는지 이해할 수 있어야 한다.
- 온라인 연결 여부와 관계없이 한 판의 최종 점수와 개인 최고 기록은 유지한다.

## 기본 점수

| 점수 요소 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 자폭 적 처치 | 100점 | 80~120점 |
| 원거리 적 처치 | 150점 | 120~180점 |
| 생존 시간 | 초당 1점 | 초당 0~2점 |
| 헤드샷 처치 | 적 기본 점수의 +50% | +25~75% |
| 권총 헤드샷 추가 | 적 기본 점수의 +50% | +25~75% |
| 샷건 근거리 처치 추가 | 적 기본 점수의 +50% | +25~75% |

생존 점수에는 콤보 배율을 적용하지 않는다. 전투 점수만 콤보의 영향을 받는다.

## 처치 점수 계산 순서

1. 처치한 적의 기본 점수를 정한다.
2. 헤드샷이면 기본 점수의 50%를 추가한다.
3. 권총 헤드샷이면 기본 점수의 50%를 다시 추가한다.
4. 샷건 근거리 처치면 기본 점수의 50%를 추가한다.
5. 해당 처치 시점의 콤보 배율을 적용한다.
6. 결과를 현재 전투 점수에 더한다.

추가 보너스는 서로 더한 후 콤보 배율을 적용한다. 샷건으로 근거리 헤드샷 처치를 하면 공통 헤드샷과 샷건 근거리 보너스를 모두 받을 수 있다.

## 무기별 점수 의도

### 권총

- 일반 처치에는 별도 무기 보너스가 없다.
- 헤드샷 처치 시 공통 헤드샷 50%와 권총 추가 50%를 받는다.
- 정확한 조준을 지속하는 플레이어의 최고 점수 잠재력이 가장 높아야 한다.

### 샷건

- 적과 6m 이내에서 처치하면 근거리 보너스를 받는다.
- 근거리 기준은 4~8m 안에서 조정한다.
- 자폭 위험을 감수하는 대신 높은 순간 점수를 얻는다.

### 라이플

- 공통 헤드샷 보너스와 콤보 보너스만 받는다.
- 별도 무기 행동 보너스는 없다.
- 안정적으로 콤보를 유지하는 역할이 강점이다.

## 연쇄 폭발 점수

- 플레이어가 피해를 준 자폭 적의 폭발로 다른 적이 죽으면 플레이어 처치로 인정한다.
- 연쇄 폭발 처치는 해당 적의 기본 점수를 받는다.
- 헤드샷과 무기별 보너스는 적용하지 않는다.
- 연쇄 폭발로 여러 적이 죽으면 각 적을 별도 처치로 처리한다.
- 각 연쇄 처치는 콤보를 이어가며 다음 처치를 위한 배율을 올린다.

## 콤보 규칙

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 콤보 제한 시간 | 3초 | 2~4초 |
| 처치당 배율 증가 | +0.25 | +0.20~0.50 |
| 최대 배율 | 3배 | 2~4배 |

- 첫 처치는 1배로 계산한다.
- 처치가 완료되면 제한 시간을 다시 3초로 되돌리고 다음 처치의 배율을 0.25 올린다.
- 제한 시간 안에 다음 적을 처치하면 높아진 배율을 적용한다.
- 제한 시간이 끝나면 콤보는 1배로 초기화한다.
- 플레이어 피격만으로 콤보를 초기화하지 않는다.
- 자폭 연쇄 처치도 콤보 제한 시간을 갱신한다.
- 최대 배율에 도달한 뒤에는 제한 시간만 갱신한다.

## 결과 기록

한 판이 끝나면 다음 값을 확정한다.

- 최종 점수
- 생존 시간
- 총 처치 수
- 자폭 적과 원거리 적 처치 수
- 헤드샷 처치 수
- 연쇄 폭발 처치 수
- 최고 콤보 배율
- 무기별 처치 수

최종 점수는 전투 점수와 생존 점수의 합이다.

## 개인 최고 기록

- 같은 브라우저에서 얻은 가장 높은 최종 점수를 개인 최고 기록으로 사용한다.
- 페이지 새로고침과 브라우저 재실행 뒤에도 유지한다.
- 브라우저 데이터가 삭제되면 초기화될 수 있다.
- 온라인 제출 성공 여부와 관계없이 갱신한다.
- 현재 점수가 개인 최고 기록을 넘으면 결과 화면에서 즉시 강조한다.
- 계정이나 닉네임을 개인 최고 기록의 소유권으로 사용하지 않는다.

## 닉네임 입력

| 항목 | 규칙 |
| --- | --- |
| 길이 | 2~12자 |
| 허용 문자 | 영문 대문자·소문자, 숫자 |
| 허용하지 않음 | 공백, 특수문자, 빈 값 |
| 중복 | 허용 |
| 대소문자 | 입력한 형태 그대로 표시 |

- 유효하지 않은 닉네임은 제출하지 않고 수정할 이유를 표시한다.
- 닉네임은 결과 화면에서만 입력한다.
- 같은 플레이어가 다른 닉네임 또는 같은 닉네임으로 여러 기록을 제출할 수 있다.

## 온라인 기록

### 상위 10개

- 모든 정상 제출 기록을 점수 내림차순으로 정렬한다.
- 같은 플레이어의 여러 기록과 같은 닉네임의 여러 기록을 모두 허용한다.
- 점수가 같으면 먼저 제출된 기록을 위에 표시한다.
- 공개 정보는 순위, 닉네임, 점수다.
- 생존 시간, 날짜, 개인 식별 정보는 공개하지 않는다.

### 현재 점수 백분위

- 정상 제출된 전체 기록과 현재 제출 기록을 비교한다.
- 현재 점수보다 높은 기록의 비율을 기준으로 `상위 X%`를 표시한다.
- 같은 점수는 같은 백분위를 표시한다.
- 최고 점수는 기록 수와 관계없이 최소 `상위 1%`로 표시한다.
- 백분위는 정수 단위로 표시하고 1~100% 범위를 사용한다.
- 백분위는 제출에 성공한 현재 기록에 대해서만 표시한다.

## 제출 상태

| 상태 | 결과 화면 동작 |
| --- | --- |
| 제출 전 | 닉네임 입력과 제출 버튼 표시 |
| 제출 중 | 중복 입력을 막고 진행 상태 표시 |
| 제출 성공 | 상위 10개와 현재 점수 백분위 갱신 |
| 입력 오류 | 잘못된 문자 또는 길이 안내 |
| 통신 실패 | 로컬 결과 유지, 실패 안내, 재시도 제공 |

제출 실패나 대기 상태가 재시작을 막아서는 안 된다.

## 우선순위

온라인 랭킹은 최종 제출에 필요한 기능이지만 다음 코어 기능 뒤에 진행한다.

1. 한 판의 시작과 종료
2. 무기 3종과 적 2종
3. 탄약 드롭과 난이도 상승
4. 점수, 콤보, 개인 최고 기록
5. 닉네임 제출, 상위 10개, 백분위

## 조정 판단

| 관찰 | 조정 방향 |
| --- | --- |
| 생존만 한 플레이가 최고점 | 생존 초당 점수 감소, 전투 보너스 증가 |
| 라이플만 사용한 점수가 항상 높음 | 라이플 탄약 효율 감소, 권총·샷건 보너스 증가 |
| 콤보가 자주 즉시 끊김 | 제한 시간 증가 |
| 콤보가 노력 없이 계속 유지됨 | 제한 시간 감소 또는 최대 배율 감소 |
| 연쇄 폭발이 모든 점수 전략을 지배함 | 폭발 범위와 자폭 적 조합 조정 |
