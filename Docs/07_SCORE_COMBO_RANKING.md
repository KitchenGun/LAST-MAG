# 점수·콤보·랭킹

## 문서 목적

이 문서는 전투 행동을 점수로 변환하는 규칙, 연속 처치 보상, 개인 최고 기록, 온라인 상위 10개와 현재 점수 백분위를 정의한다.

## 점수 설계 원칙

- 전투 실력이 생존 시간보다 큰 점수 차이를 만든다.
- 위험하거나 정밀한 행동은 안전한 공격보다 더 높은 점수를 준다.
- 콤보는 적을 빠르게 연속 처치하도록 유도한다.
- 점수 규칙은 결과 화면만 보아도 어떤 행동이 보상됐는지 이해할 수 있어야 한다.
- 온라인 연결 여부와 관계없이 한 판의 최종 점수와 개인 최고 기록은 유지한다.

## 기본 점수

| 점수 요소 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 자폭 적 처치 | 50점 | 40~70점 |
| 일반 근거리 적 처치 | 70점 | 50~90점 |
| 원거리 적 처치 | 100점 | 80~120점 |
| 생존 시간 | 초당 1점 | 초당 0~2점 |
| 특화 무기 처치 | +30점 | 플레이테스트 후 조정 |
| 헤드샷 처치 | +30점 | 플레이테스트 후 조정 |
| 스왑킬 | +70점 | 플레이테스트 후 조정 |
| 콤보 | `10 × (C-1)`점 | 처치당 +10점 |
| 스킬 보너스 | `2B` | 기본 점수의 총 300% |

전투 점수는 다음 식으로 계산한다.

`획득 점수 = B + 특화 무기 30 + 헤드샷 30 + 스왑킬 70 + 10 × (C-1) + 스킬 보너스 2B`

`B`는 적 기본 점수, `C`는 현재 처치로 증가한 콤보 수다. 생존 점수에는 전투 가산 보너스를 적용하지 않는다.

## 처치 점수 계산 순서

1. 처치한 적의 기본 점수를 정한다.
2. 플레이어 귀속 처치이면 콤보 수를 1 올리고 5초 타이머를 갱신한다.
3. 마지막 공격의 헤드샷, 적별 특화 무기, 스왑킬 조건을 각각 확인한다.
4. 수류탄·로켓, 불릿타임 총기 처치, 스킬 귀속 연쇄이면 `2B`를 더한다.
5. 기본 점수와 충족한 가산점을 합해 전투 점수에 더한다.

## 적별 권장 무기

| 적 종류 | 권장 무기 | 기본 점수 |
| --- | --- | ---: |
| 자폭형 | 권총 | 50점 |
| 일반 근거리 | 샷건 | 70점 |
| 원거리 | 라이플 계열(라이플·DMR) | 100점 |

특화 무기 일치는 헤드샷과 독립된 +30점 조건이다.

## 스왑킬 점수

- 직전 득점 처치와 현재 처치가 모두 직접 총기 처치여야 한다.
- 두 처치의 무기가 다르고 직전 처치 후 2초 이내일 때 +70점을 받는다.
- 같은 총기, 2초 초과, 직전 직접 총기 처치가 없으면 적용하지 않는다.
- 두 직접 처치 사이에 수류탄·로켓 또는 연쇄 처치가 발생하면 후보를 초기화한다.
- 불릿타임 중 총기 처치는 직접 총기 처치이면서 스킬 처치이므로 스왑킬과 스킬 보너스를 함께 받을 수 있다.

## 고유 스킬 점수

- 수류탄과 로켓의 직접 폭발 처치는 `B + 2B + 콤보 가산점`으로 계산해 총 300% 기본 점수를 받는다.
- 수류탄·로켓 직접 처치는 헤드샷, 특화 무기, 스왑킬 보너스를 받지 않는다.
- 불릿타임 중 총기 직접 처치는 기존 총기 가산점에 `2B` 스킬 보너스를 추가한다.
- 스킬이 자폭형 적의 2차 폭발을 유발하면 이후 플레이어 귀속 연쇄에도 `2B` 스킬 보너스를 적용한다.
- 한 폭발로 여러 적이 동시에 죽으면 처치마다 콤보 수를 1씩 올려 각 처치의 `C`를 정한다.
- 수류탄·로켓의 직접 폭발과 여기서 시작된 플레이어 귀속 연쇄 처치는 모두 해당 클래스의 스킬 처치에도 포함한다.
- 불릿타임 활성 중 발생한 총기 직접 처치와 플레이어 귀속 연쇄 처치는 모두 저격수의 스킬 처치에 포함한다.
- 자연 자폭과 비귀속 연쇄 폭발은 클래스 스킬 처치에 포함하지 않는다.

## 연쇄 폭발 점수

- 플레이어가 직접 처치했거나 플레이어 귀속 연쇄 폭발로 쓰러진 자폭형의 폭발만 플레이어 귀속을 계승한다.
- 일반 플레이어 귀속 연쇄 처치는 `B + 10 × (C-1)`만 적용하고 헤드샷·특화 무기·스왑킬 보너스를 받지 않는다.
- 자연 자폭과 비귀속 연쇄 폭발은 점수와 콤보를 지급하지 않는다.
- 스킬 귀속 연쇄는 일반 연쇄 규칙에 `2B`를 추가한다.
- 한 폭발의 동시 처치도 각 처치마다 콤보 수를 1씩 올리고 마지막 처치 뒤 타이머를 5초로 갱신한다.

## 콤보 규칙

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 콤보 수 | 0부터 상한 없이 증가 | 고정 |
| 점수 보너스 | `10 × (C-1)`점 | 처치당 +10점 |
| 유지 시간 | 5초 | 고정 |

- 비활성 상태는 콤보 0이다.
- 첫 처치는 `C=1`로 콤보 가산점이 없고 두 번째부터 처치당 가산점이 10점씩 커진다.
- 모든 플레이어 귀속 처치가 콤보를 1 올리고 실시간 타이머를 5초로 갱신한다.
- 유지 시간이 끝나면 콤보를 0으로 초기화한다.
- 플레이어 피격만으로 콤보를 초기화하지 않는다.
- 콤보 수에는 상한이 없다.

## 결과 기록

한 판이 끝나면 다음 값을 확정한다.

- 최종 점수
- 생존 시간
- 총 처치 수
- 자폭형, 일반 근거리, 원거리 적 처치 수
- 헤드샷 처치 수
- 연쇄 폭발 처치 수
- 최고 콤보 수 `MAX COMBO xN`
- 선택 클래스의 주무기와 권총 처치 수
- 선택 클래스의 스킬 기여 처치 수

스킬이 유발한 연쇄 처치는 스킬 기여 처치와 연쇄 폭발 처치에 각각 포함한다.

최종 점수는 전투 점수와 생존 점수의 합이다.

## 개인 최고 기록

- 같은 브라우저에서 얻은 가장 높은 최종 점수를 개인 최고 기록으로 사용한다.
- 페이지 새로고침과 브라우저 재실행 뒤에도 유지한다.
- 브라우저 데이터가 삭제되면 초기화될 수 있다.
- 온라인 제출 성공 여부와 관계없이 갱신한다.
- 현재 점수가 개인 최고 기록을 넘으면 결과 화면에서 즉시 강조한다.
- 계정이나 닉네임을 개인 최고 기록의 소유권으로 사용하지 않는다.

## 닉네임 입력

| 항목 | 규칙 |
| --- | --- |
| 길이 | 2~12자 |
| 허용 문자 | 영문 대문자·소문자, 숫자 |
| 허용하지 않음 | 공백, 특수문자, 빈 값 |
| 중복 | 허용 |
| 대소문자 | 입력한 형태 그대로 표시 |

- 유효하지 않은 닉네임은 제출하지 않고 수정할 이유를 표시한다.
- 닉네임은 결과 화면에서만 입력한다.
- 같은 플레이어가 다른 닉네임 또는 같은 닉네임으로 여러 기록을 제출할 수 있다.

## 온라인 기록

### 상위 10개

- 모든 정상 제출 기록을 점수 내림차순으로 정렬한다.
- 같은 플레이어의 여러 기록과 같은 닉네임의 여러 기록을 모두 허용한다.
- 점수가 같으면 먼저 제출된 기록을 위에 표시한다.
- 공개 정보는 순위, 닉네임, 점수다.
- 생존 시간, 날짜, 개인 식별 정보는 공개하지 않는다.

### 현재 점수 백분위

- 정상 제출된 전체 기록과 현재 제출 기록을 비교한다.
- 현재 점수보다 높은 기록의 비율을 기준으로 `상위 X%`를 표시한다.
- 같은 점수는 같은 백분위를 표시한다.
- 최고 점수는 기록 수와 관계없이 최소 `상위 1%`로 표시한다.
- 백분위는 정수 단위로 표시하고 1~100% 범위를 사용한다.
- 백분위는 제출에 성공한 현재 기록에 대해서만 표시한다.

## 제출 상태

| 상태 | 결과 화면 동작 |
| --- | --- |
| 제출 전 | 닉네임 입력과 제출 버튼 표시 |
| 제출 중 | 중복 입력을 막고 진행 상태 표시 |
| 제출 성공 | 상위 10개와 현재 점수 백분위 갱신 |
| 입력 오류 | 잘못된 문자 또는 길이 안내 |
| 통신 실패 | 로컬 결과 유지, 실패 안내, 재시도 제공 |

제출 실패나 대기 상태가 재시작을 막아서는 안 된다.

## 우선순위

온라인 랭킹은 최종 제출에 필요한 기능이지만 다음 코어 기능 뒤에 진행한다.

1. 한 판의 시작과 종료
2. 클래스 3종의 고정 로드아웃·고유 스킬과 적 3종
3. 탄약 드롭과 난이도 상승
4. 점수, 콤보, 개인 최고 기록
5. 닉네임 제출, 상위 10개, 백분위

## 조정 판단

| 관찰 | 조정 방향 |
| --- | --- |
| 생존만 한 플레이가 최고점 | 생존 초당 점수 감소, 전투 보너스 증가 |
| 한 무기만 사용한 점수가 항상 높음 | 특화 무기·스왑킬 가산점과 적 조합 조정 |
| 콤보가 자주 즉시 끊김 | 고정 5초 유지 시간과 생성 간격 조정 |
| 콤보가 노력 없이 계속 유지됨 | 고정 유지 시간 또는 적 생성 빈도 조정 |
| 연쇄 폭발이 모든 점수 전략을 지배함 | 폭발 범위와 자폭 적 조합 조정 |
