# 점수·콤보·랭킹

## 문서 목적

이 문서는 전투 행동을 점수로 변환하는 규칙, 연속 처치 보상, 개인 최고 기록, 온라인 상위 10개와 현재 점수 백분위를 정의한다.

## 점수 설계 원칙

- 전투 실력이 생존 시간보다 큰 점수 차이를 만든다.
- 위험하거나 정밀한 행동은 안전한 공격보다 더 높은 점수를 준다.
- 콤보는 적을 빠르게 연속 처치하도록 유도한다.
- 점수 규칙은 결과 화면만 보아도 어떤 행동이 보상됐는지 이해할 수 있어야 한다.
- 온라인 연결 여부와 관계없이 한 판의 최종 점수와 개인 최고 기록은 유지한다.

## 기본 점수

| 점수 요소 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 자폭 적 처치 | 100점 | 80~120점 |
| 일반 근거리 적 처치 | 100점 | 80~120점 |
| 원거리 적 처치 | 150점 | 120~180점 |
| 생존 시간 | 초당 1점 | 초당 0~2점 |
| 기본 사살 행동 계수 | ×0.7 | 플레이테스트 후 조정 |
| 헤드샷 또는 권장 무기 중 하나 충족 | ×1.0 | 플레이테스트 후 조정 |
| 헤드샷과 권장 무기 모두 충족 | ×1.5 | 플레이테스트 후 조정 |

생존 점수에는 콤보 배율을 적용하지 않는다. 전투 점수만 콤보의 영향을 받는다.

## 처치 점수 계산 순서

1. 처치한 적의 기본 점수를 정한다.
2. 마지막 공격이 머리 판정으로 사망시켰는지 확인한다.
3. 적별 권장 무기가 일치하는지 확인한다.
4. 두 조건 모두 불충족이면 ×0.7, 하나만 충족하면 ×1.0, 모두 충족하면 ×1.5 행동 계수를 정한다.
5. 해당 처치에 적용할 콤보 레벨과 배율을 정한다.
6. `적 기본 점수 × 행동 계수 × 콤보 배율`을 가장 가까운 정수로 반올림해 전투 점수에 더한다.

## 적별 권장 무기

| 적 종류 | 권장 무기 | 기본 점수 |
| --- | --- | ---: |
| 자폭형 | 권총 | 100점 |
| 일반 근거리 | 샷건 | 100점 |
| 원거리 | 라이플 | 150점 |

권장 무기 일치는 헤드샷과 독립된 조건이다. 적에 맞는 무기 선택과 정확한 마무리를 동시에 수행할 때 ×1.5를 얻는다.

## 연쇄 폭발 점수

- 플레이어가 직접 처치했거나 플레이어 귀속 연쇄 폭발로 쓰러진 자폭형의 폭발만 플레이어 귀속을 계승한다.
- 플레이어 귀속 연쇄 처치는 적 종류와 무관하게 ×0.7 행동 계수를 적용하고 헤드샷·권장 무기 보너스를 받지 않는다.
- 자연 자폭과 비귀속 연쇄 폭발은 점수와 콤보를 지급하지 않는다.
- 한 폭발로 여러 적이 동시에 죽으면 폭발 직전 콤보 레벨을 모든 처치 점수에 동일하게 적용한다.
- 점수 계산이 끝난 뒤 처치 수만큼 콤보 레벨을 올리고 최종 레벨의 유지 시간으로 타이머를 한 번 갱신한다.

## 콤보 규칙

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 콤보 레벨 | 0~10 | 고정 |
| 점수 배율 | ×1.0~×2.8 | 레벨당 +0.2 |
| 유지 시간 | 3초~1.5초 | 레벨에 따라 선형 감소 |

- 비활성 상태는 콤보 0레벨·×1.0이다.
- 첫 연속 처치는 1레벨 ×1.0, 열 번째 처치는 10레벨 ×2.8을 적용한다.
- 레벨별 배율은 `1 + 0.2 × (레벨 - 1)`이다.
- 레벨별 유지 시간은 `3 - 1.5 × (레벨 - 1) / 9`초다.
- 처치 시 해당 처치 레벨로 점수를 계산하고 그 레벨의 유지 시간으로 타이머를 갱신한다.
- 유지 시간이 끝나면 콤보 0레벨·×1.0으로 초기화한다.
- 플레이어 피격만으로 콤보를 초기화하지 않는다.
- 최대 레벨에서 추가 처치하면 10레벨을 유지하고 타이머만 갱신한다.

## 결과 기록

한 판이 끝나면 다음 값을 확정한다.

- 최종 점수
- 생존 시간
- 총 처치 수
- 자폭형, 일반 근거리, 원거리 적 처치 수
- 헤드샷 처치 수
- 연쇄 폭발 처치 수
- 최고 콤보 레벨과 배율
- 무기별 처치 수

최종 점수는 전투 점수와 생존 점수의 합이다.

## 개인 최고 기록

- 같은 브라우저에서 얻은 가장 높은 최종 점수를 개인 최고 기록으로 사용한다.
- 페이지 새로고침과 브라우저 재실행 뒤에도 유지한다.
- 브라우저 데이터가 삭제되면 초기화될 수 있다.
- 온라인 제출 성공 여부와 관계없이 갱신한다.
- 현재 점수가 개인 최고 기록을 넘으면 결과 화면에서 즉시 강조한다.
- 계정이나 닉네임을 개인 최고 기록의 소유권으로 사용하지 않는다.

## 닉네임 입력

| 항목 | 규칙 |
| --- | --- |
| 길이 | 2~12자 |
| 허용 문자 | 영문 대문자·소문자, 숫자 |
| 허용하지 않음 | 공백, 특수문자, 빈 값 |
| 중복 | 허용 |
| 대소문자 | 입력한 형태 그대로 표시 |

- 유효하지 않은 닉네임은 제출하지 않고 수정할 이유를 표시한다.
- 닉네임은 결과 화면에서만 입력한다.
- 같은 플레이어가 다른 닉네임 또는 같은 닉네임으로 여러 기록을 제출할 수 있다.

## 온라인 기록

### 상위 10개

- 모든 정상 제출 기록을 점수 내림차순으로 정렬한다.
- 같은 플레이어의 여러 기록과 같은 닉네임의 여러 기록을 모두 허용한다.
- 점수가 같으면 먼저 제출된 기록을 위에 표시한다.
- 공개 정보는 순위, 닉네임, 점수다.
- 생존 시간, 날짜, 개인 식별 정보는 공개하지 않는다.

### 현재 점수 백분위

- 정상 제출된 전체 기록과 현재 제출 기록을 비교한다.
- 현재 점수보다 높은 기록의 비율을 기준으로 `상위 X%`를 표시한다.
- 같은 점수는 같은 백분위를 표시한다.
- 최고 점수는 기록 수와 관계없이 최소 `상위 1%`로 표시한다.
- 백분위는 정수 단위로 표시하고 1~100% 범위를 사용한다.
- 백분위는 제출에 성공한 현재 기록에 대해서만 표시한다.

## 제출 상태

| 상태 | 결과 화면 동작 |
| --- | --- |
| 제출 전 | 닉네임 입력과 제출 버튼 표시 |
| 제출 중 | 중복 입력을 막고 진행 상태 표시 |
| 제출 성공 | 상위 10개와 현재 점수 백분위 갱신 |
| 입력 오류 | 잘못된 문자 또는 길이 안내 |
| 통신 실패 | 로컬 결과 유지, 실패 안내, 재시도 제공 |

제출 실패나 대기 상태가 재시작을 막아서는 안 된다.

## 우선순위

온라인 랭킹은 최종 제출에 필요한 기능이지만 다음 코어 기능 뒤에 진행한다.

1. 한 판의 시작과 종료
2. 무기 3종과 적 3종
3. 탄약 드롭과 난이도 상승
4. 점수, 콤보, 개인 최고 기록
5. 닉네임 제출, 상위 10개, 백분위

## 조정 판단

| 관찰 | 조정 방향 |
| --- | --- |
| 생존만 한 플레이가 최고점 | 생존 초당 점수 감소, 전투 보너스 증가 |
| 한 무기만 사용한 점수가 항상 높음 | 적별 권장 무기 계수와 적 조합 조정 |
| 콤보가 자주 즉시 끊김 | 레벨별 유지 시간 곡선 완화 |
| 콤보가 노력 없이 계속 유지됨 | 레벨별 유지 시간 곡선 강화 |
| 연쇄 폭발이 모든 점수 전략을 지배함 | 폭발 범위와 자폭 적 조합 조정 |
