# 시각·오디오 방향

## 문서 목적

이 문서는 레벨, 적, 무기, 탄약, UI, 전투 효과와 사운드가 하나의 군사 산업 SF 분위기를 유지하면서 플레이 정보를 명확히 전달하도록 기준을 정한다.

## 핵심 콘셉트

전장은 거대한 전함 내부의 수직 작업 구역이다. 검은 장갑 강철, 건조한 콘크리트, 노출된 배관과 정비 구조가 무거운 군사 시설의 인상을 만든다. 중앙에는 고정된 작업 플랫폼이 있고 외곽 통로와 상부 발판이 이를 둘러싼다.

분위기는 어둡지만 적, 투사체, 탄약, 이동 경로가 가려져서는 안 된다. 안개 없이 청백색 작업등으로 공간을 읽게 하고 붉은 경고등은 위험 신호에 제한한다.

## 색상 역할

| 색상군 | 역할 |
| --- | --- |
| 검정·차콜 | 전함 벽체, 공허, 배경 깊이 |
| 회색·콘크리트색 | 이동 가능한 구조물과 플랫폼 |
| 청백색 | 작업등, 안전한 이동 경로, 일반 인터페이스 |
| 붉은색 `#EA4047` | 권총 탄약과 권총 관련 정보, 근접 적 공격, 자폭 예고, 피격, 위험 구역 |
| 겨자색 `#C8B64A`·`#786D24` | 자폭 폭발 가스, 원거리 공격 충전·투사체·착탄 흔적 |
| 초록색 `#35C759` | 샷건 탄약과 샷건 관련 정보 |
| 파란색 `#2C87E8` | 라이플 탄약과 라이플·DMR 관련 정보 |

탄약 색은 아이콘과 외형 차이를 보조하며 색만으로 구분하지 않는다.

## 환경 방향

- 큰 벽체와 플랫폼은 단순하고 강한 형태를 사용한다.
- 노출된 배관, 케이블, 터빈, 난간은 이동 가능한 길을 가리지 않는 범위에서 배치한다.
- 중앙 플랫폼, 외곽 순환로, 상부 발판은 재질과 조명으로 구분한다.
- 붉은 경고 비콘은 적 진입 통로와 위험 예고에 집중한다.
- 멀리 있는 적과 투사체를 가리는 안개와 과도한 연무를 사용하지 않는다.
- 실시간 파괴 표현은 사용하지 않는다.
- 장식보다 전투 동선과 실루엣 가독성을 우선한다.

## 적 시각 방향

### 비인간형 6족 자폭 적

- 큰 폭발성 캡시드와 짧은 관절 다리 세 쌍으로 구성된 낮은 실루엣을 사용한다.
- 젖은 생체 조직과 검은 힘줄을 공통 모티브로 사용하고 캡시드 기관에 붉은색 `#EA4047`을 제한적으로 적용한다.
- 폭발 예고가 시작되면 2.5초 동안 붉은 빛, 다리 수축, 캡시드 팽창을 함께 강화한다.
- 폭발 범위는 직접 원 대신 0.2초마다 4개씩 차오르는 겨자색 가스로 4m 안을 읽히게 하며, 폭발 시 48개의 더 짙은 가스 구름으로 유지한다.
- 사망과 자폭을 서로 구분하되 연쇄 폭발은 한눈에 이어져 보여야 한다.

필요 애니메이션은 대기, 다리 이동, 폭발 예고이다.

### 일반 근거리 인간형 적

- 실제 인간 비율의 유기체와 길게 변형된 양팔 칼날, 빠른 전진 자세로 식별한다.
- 젖은 생체 조직과 검은 힘줄을 기본으로 하고 머리 기관에 초록색 `#35C759`을 제한적으로 적용한다.
- 공격 범위에서 멈춘 뒤 양팔 칼날을 머리 위로 들어 내려찍어 타격 방향을 예고한다.
- 예고 시작 후 방향이 고정됐음을 자세 변화로 읽을 수 있어야 한다.

필요 애니메이션은 대기, 빠른 이동, 내려찍기 공격, 피격, 사망이다.

### 원거리 공격 인간형 적

- 실제 인간 비율의 유기체와 구강 발사구, 무거운 직립 자세로 두 근거리 적과 구분한다.
- 젖은 생체 조직과 검은 힘줄을 기본으로 하고 머리 기관에 파란색 `#2C87E8`을 제한적으로 적용한다.
- 이동, 정지, 구강 충전, 발사의 단계가 머리와 상체 자세 변화로 읽혀야 한다.
- 공격 예고에는 구강 방향과 겨자색 가스 충전 표시를 함께 사용한다.
- 원거리 투사체는 작은 불투명 코어와 짧은 가스 흔적으로 표현하고, 자폭 폭발은 4m 범위의 큰 가스 구름으로 구분한다.
- 재배치 중인 상태와 발사 직전 상태를 혼동하지 않게 한다.

필요 애니메이션은 대기, 무거운 이동, 구강 충전·발사, 피격, 사망이다.

## 무기 시각 방향

| 무기 | 형태 | 발사 표현 | 화면 움직임 |
| --- | --- | --- | --- |
| 권총 | 작고 얇은 정밀 실루엣 | 짧고 선명한 총구 효과 | 빠르게 회복되는 짧은 반동 |
| 샷건 | 넓고 무거운 전면부 | 넓게 퍼지는 강한 순간 효과 | 크고 느리게 회복되는 반동 |
| 라이플 | 길고 안정적인 실루엣 | 반복되는 일정한 총구 효과 | 연속 사격 중 누적되는 작은 반동 |
| DMR | 길고 무거운 정밀 실루엣 | 짧은 총구 효과와 관통 탄도 | 강하지만 빠르게 복귀하는 반동 |

- 네 일반 무기와 수류탄·로켓 런처는 화면 하단 실루엣만으로 구분되어야 한다.
- 보유 탄약이 0인 상태의 사격 입력은 발사와 확실히 다른 짧은 HUD 강조로 알린다.
- 무기 외형은 실제 총기 재현보다 게임 안의 역할 구분을 우선한다.
- 실제 조준 반동은 권총 `2.2°/0.35°`, 라이플 `2.3°/0.32°`, DMR `3.2°/0.45°`, 샷건 `4.6°/0.85°`, 로켓 `5.6°/1.1°`의 Pitch/Yaw 기준값을 사용한다.
- 발사별 Pitch Random은 권총 `10%`, 라이플 `12%`, DMR `10%`, 샷건·로켓 `15%`이며 실제 Yaw는 기준값의 `75~100%`, 실제 Pitch의 40% 이하로 제한한다.
- 반동은 현재 보이는 값에 누적되며 Soft Cap 접근 시 추가 Pitch를 25%까지 줄이고 비정상 누적은 Hard Cap으로 제한한다. Pitch 한계 밖의 보이지 않는 반동은 저장하지 않는다.
- 상승은 완만한 Ease-Out Quad, 복귀는 Ease-Out Cubic을 사용해 모두 초반이 빠르고 끝에서 느려진다. 무기 교체만으로 진행 중인 카메라 회복 프로필을 바꾸지 않는다.
- 단발은 기본 조준으로 완전히 복귀한다. 성공한 같은 무기 발사가 권총 0.24초·라이플 0.32초·DMR 0.42초 안에 이어지면 연속 사격으로 보고 마지막 복귀 시작값의 20%·35%·25%를 현재 기본 조준각에 남긴다. 샷건과 로켓에는 잔류를 적용하지 않는다.
- 실제 조준과 별도로 권총 `0.35°/0.05°/0.12°`, 라이플 `0.25°/0.05°/0.12°`, DMR `0.50°/0.10°/0.18°`, 샷건 `0.75°/0.15°/0.28°`, 로켓 `1.00°/0.20°/0.35°`의 작은 Pitch/Yaw/Roll Camera Rock을 적용하며 발사 Ray에는 포함하지 않는다.
- 무기 모델은 권총 `후퇴 0.065m/좌우 0.018m/Pitch 5°`, 샷건 `0.18m/0.04m/11°`, 라이플 `0.06m/0.013m/4°`, DMR `0.12m/0.027m/6.5°`의 속도 충격을 사용한다. 위치·회전 스프링이 이전 발사의 관성을 이어받아 약하게 한 번 Overshoot한 뒤 안정된다.
- 권총은 발사마다 연기 2개, 샷건은 6개, 라이플은 3발마다 1개를 표시하고 DMR은 기존 관통 탄도와 총구 연기를 유지한다.

## 탄약 시각 방향

| 탄약 | 색 | 형태 |
| --- | --- | --- |
| 권총 | 붉은색 `#EA4047` | 작고 단단한 상자 또는 짧은 탄창 형태 |
| 샷건 | 초록색 `#35C759` | 굵은 원통이나 묶음 형태 |
| 라이플 | 파란색 `#2C87E8` | 길고 분할된 탄창 형태. 척탄병은 라이플 실루엣, 저격수는 DMR 실루엣 표시 |

- 멀리서도 탄약 종류를 구분할 수 있는 크기와 윤곽을 유지한다.
- 탄약 상자 위에는 해당 무기의 실루엣을 같은 색과 발광 강도로 표시하고, 실루엣은 항상 카메라 정면을 향하되 벽 뒤에서는 상자와 함께 가린다.
- 바닥과 색이 섞이지 않도록 약한 발광 또는 윤곽을 사용한다.
- 획득 가능 상태와 최대 보유로 획득할 수 없는 상태를 구분한다.
- 획득 시 해당 탄약의 색, 아이콘, 증가량을 짧게 표시한다.

## 전투 효과

필수 효과는 다음으로 제한한다.

- 권총·샷건·라이플·DMR 총구 효과
- DMR 관통 탄도
- 수류탄 투척 후 `4.5/5.5/6.5초`에 기존 폭발 VFX와 폭발음을 반복하고, 첫 폭발부터 마지막 폭발까지 메시를 같은 위치에 유지
- 로켓 런처는 발사 후 약 0.70초 스프링 반동 동안 화면에 남고, 별도 초록색 발광 캡슐 투사체가 비행해 충돌 또는 5초 후 폭발한다. 캡슐은 최종 투사체 아트 전까지 사용하는 임시 표현이다.
- 불릿타임 시작 시 월드 화면을 0.15초 동안 흑백으로 전환하고 종료 시 원래 색상으로 복귀한다. Overlay HUD 색상은 유지한다.
- DMR 정조준은 기존 피해 비네팅 형태를 재사용한 알파 0.68의 검은 가장자리와 중앙 조준선으로 표현한다. FOV와 비네팅은 0.12초 동안 전환한다.
- 불릿타임 중 무기 Viewmodel 반동과 총구 화염·연기·탄도 파티클은 세계와 같은 35% 속도로 재생한다. 배경음악도 Pitch를 0.35로 낮추며 조준·RPM·총성은 실시간을 유지한다.
- 플레이어 사망 시 약 3.3초 동안 카메라가 지면으로 쓰러지고 화면 가장자리는 적색 비네팅·단색 틴트로 강해진다. 현재 무기 또는 준비 중인 수류탄·런처 메시 하나는 물리적으로 떨어지며, 사망 음성 `SFX_Death_VitalSignsLow`를 최우선으로 끝까지 재생한다.
- 일반 적중
- 헤드샷
- 적 처치
- 자폭 예고
- 자폭과 연쇄 폭발
- 원거리 적 공격 예고와 투사체
- 플레이어 피격과 낮은 체력
- 체력 회복 시작
- 탄약 드롭과 획득
- 콤보 상승과 종료

효과는 적과 투사체를 가리지 않아야 하며 한 화면에 여러 폭발이 발생해도 공격 예고를 읽을 수 있어야 한다.
구조물 탄착은 주황색 스파크로 구분한다. 근거리·원거리 인간형 적 직접 총기 적중은 비발광 초록·올리브 체액 파편과 최대 2m 뒤 구조물의 초록 표면 흔적으로 과장해 표시한다. 표면 흔적은 4초 유지, 최대 20개를 재사용하며 혈액이나 고어로 표현하지 않는다. 자폭형 적은 기존 올리브·적갈색 외피 파편만 사용한다.

## UI 시각 방향

- 전함의 진단 장비처럼 간결한 선, 숫자, 경고 표시를 사용한다.
- 장식 프레임보다 체력, 탄약, 점수, 콤보의 가독성을 우선한다.
- 권총의 붉은색 `#EA4047`은 위험 신호와 공유하되, 위험은 아이콘·문구·점멸로 구분하고 일반 점수에는 사용하지 않는다.
- 콤보 카운트는 1콤보 흰색에서 10콤보 붉은색으로 변하고, 크로스헤어 하단의 득점 피드는 흰색을 유지한다.
- 사용자 제공 탄환 Sprite의 비율과 투명도를 보존해 5초 잔여 시간을 오른쪽부터 줄어드는 5발로 표시한다.
- `1`번 주무기, `2`번 권총과 `F` 스킬의 번호·아이콘을 게임 화면과 결과 화면에서 동일하게 유지한다.
- 결과 화면은 최종 점수와 개인 최고 기록을 가장 크게 보여준다.

## 사운드 콘셉트

배경음악은 어두운 인더스트리얼 전자음과 반복되는 기계 리듬을 사용한다. 시간이 지날수록 새 곡으로 바꾸기보다 같은 음악 안에서 압박이 커지는 인상을 준다.

### 필수 효과음

- 총성은 발소리와 AudioSource를 분리하고 최근 두 총성만 겹치게 해 연속 사격이 지속음처럼 뭉개지지 않게 한다.
- DMR을 제외한 총성 피치는 발사마다 `0.98~1.02` 범위에서 미세하게 변주한다.
- DMR은 `Hand Gun 3`과 `Hand Gun_6` 각각에 피치 `0.97/1.00/1.03`, 음량 `0.98/1.00/0.97`을 조합한 6변형 셔플백을 사용한다. 같은 변형의 연속 재생과 같은 원본 클립의 3연속 재생은 셔플 경계에서도 금지한다.

| 원거리 적 | 이동, 조준 예고, 발사, 투사체 통과 |
| 플레이어 | 피격, 낮은 체력, 회복 시작, 사망 |
| 탄약 | 드롭, 무기별 획득 |
| 점수 | 콤보 상승, 5초 콤보 종료, 최고 콤보 수, 최고 기록 갱신 |
| UI | 시작, 선택, 제출 성공, 제출 실패, 재시작 |

## 사운드 우선순위

동시에 여러 소리가 발생하면 다음 순서를 유지한다.

1. 플레이어 사망과 즉시 위험한 공격 예고
2. 자폭 예고와 원거리 발사
3. 플레이어 피격과 낮은 체력
4. 현재 무기 발사
5. 헤드샷과 적 처치
6. 탄약 획득과 콤보
7. 배경음악과 환경음

배경음악과 환경음이 공격 예고를 가리면 안 된다.

## WebGL 표현 원칙

- 화면을 채우는 투명 효과와 긴 잔상은 제한한다.
- 적, 투사체, 탄약이 늘어나는 상황에서도 기본 색과 실루엣을 유지한다.
- 사운드 변형 수보다 적 공격 예고와 무기 구분에 필요한 소리를 우선한다.
- 텍스처와 모델의 세부 묘사보다 화면에서 읽히는 형태를 우선한다.
- 외부 브라우저에서 색, 밝기, 음량 차이를 확인한다.

## 완료 기준

- 스크린샷 한 장에서 군사 산업 SF 공간임을 알아볼 수 있다.
- 적 3종을 실루엣, 색, 동작만으로 구분할 수 있다.
- 클래스 3종의 주무기와 스킬을 화면 하단 형태와 소리로 구분할 수 있다.
- 일반 무기 4종과 탄약 3종을 색을 보지 않고도 형태와 아이콘으로 구분할 수 있다. 저격수의 파란 라이플 탄약은 DMR 실루엣으로 식별된다.
- 자폭과 원거리 공격 예고가 폭발 효과 속에서도 보인다.
- 사운드를 끈 상태와 화면 효과를 줄인 상태에서도 핵심 전투 정보를 이해할 수 있다.
