# 코어 루프와 한 판 구조

## 문서 목적

이 문서는 게임 시작부터 사망, 기록 확인, 재시작까지 플레이어가 겪는 순서와 반복 행동을 정의한다.

## 전체 흐름

1. 시작 화면에서 목표와 조작을 확인하고 척탄병, 공병, 저격수 중 하나를 선택한다.
2. 플레이를 시작하면 선택한 클래스의 주무기, 권총, 고유 스킬을 보유한다.
3. 계속 등장하는 자폭형·일반 근거리·원거리 적을 처치한다.
4. 적이 떨어뜨린 무기별 탄약을 회수한다.
5. 남은 탄약과 적 거리에 맞춰 두 무기를 바꾸고 고유 스킬을 사용한다.
6. 헤드샷, 권장 무기와 연속 처치로 점수를 높인다.
7. 시간이 지날수록 적의 생성 빈도, 동시 수, 조합 압박이 증가한다.
8. 피해를 피하며 회복 시간을 확보한다.
9. 체력이 0이 되면 한 판이 끝난다.
10. 결과 화면에서 점수, 생존 시간, 개인 최고 기록을 확인한다.
11. 닉네임을 입력해 기록을 제출하면 상위 10개와 현재 점수의 백분위를 확인한다.
12. 시작 화면으로 돌아가 클래스를 다시 선택한다.

## 전투 반복 루프

`위협 확인 → 무기·스킬 선택 → 조준·공격 → 적 처치 → 탄약 위치 확인 → 이동·회수 → 다음 위협 확인`

이 반복에서 탄약 회수는 전투가 끝난 뒤의 보상 단계가 아니라 다음 교전을 시작하기 위한 위험 행동이다. 탄약이 적 위치에 떨어지므로 플레이어는 적이 밀집한 곳으로 다시 접근해야 한다.

## 한 판의 구간

난이도는 웨이브로 끊지 않고 시간에 따라 연속으로 변한다. 아래 구간은 플레이 감정을 설명하기 위한 기준이며 화면에 별도 웨이브로 표시하지 않는다.

| 경과 시간 | 전투 상태 | 플레이 목적 |
| --- | --- | --- |
| 0~1분 | 동시 적 목표 3명에서 12명으로 증가 | 조작, 무기 전환, 탄약 회수 이해 |
| 1~3분 | 동시 적 목표 12명에서 48명으로 증가 | 세 적의 우선순위와 순환 동선 학습 |
| 3~5분 | 동시 적 목표 48명에서 108명으로 증가 | 콤보와 생존을 동시에 관리 |
| 5분 이후 | 제곱식으로 동시 적 목표 증가 | 자원 부족과 위치 선정 속에서 최고 기록 도전 |

5분 이후에도 적 능력치는 변하지 않는다. 동시 적 목표는 경과 시간 `t`분에 대해 `floor(3 × (t + 1)²)`로 계속 증가한다.

## 시작 상태

- 체력은 최대치 100으로 시작한다.
- 선택한 클래스는 주무기와 권총의 최대 보유 탄약을 가지고 시작한다.
- 주무기 시작량은 척탄병 라이플 탄약 30발, 공병 샷건 탄약 6발, 저격수 라이플 탄약 12발이며 권총은 15발이다. DMR은 별도 탄약 없이 라이플 탄약을 소비한다.
- 클래스별 체력과 이동 속도는 같고 패시브는 없다.
- 점수, 콤보, 생존 시간은 0에서 시작한다.
- 적은 플레이어가 시점과 이동을 확인할 짧은 여유 후 등장한다.
- 자폭형·일반 근거리·원거리 적은 매 3회 생성마다 각각 한 번씩 등장하고 순서만 무작위로 섞는다.

## 전투 중 자원 순환

- 적을 처치할 때마다 선택한 클래스의 주무기 또는 권총 탄약이 50% 확률로 등장한다.
- 스킬은 탄약을 사용하지 않고 효과 종료 뒤 클래스별 쿨다운을 적용한다.
- 탄약은 접촉 즉시 해당 무기의 보유 탄약에 추가된다.
- 탄약이 가득 찬 종류도 획득할 수 없으며 바닥에 남아 다른 선택 기회를 제공한다.
- 탄약 종류는 멀리서도 무기와 연결해 알아볼 수 있어야 한다.

## 체력과 회복 흐름

- 피해를 받으면 체력이 감소하고 회복 대기 시간이 처음부터 다시 시작한다.
- 5초 동안 피해를 받지 않으면 초당 20의 속도로 회복한다.
- 회복 중 다시 피해를 받으면 즉시 회복이 멈춘다.
- 회복은 최대 체력에서 멈춘다.
- 회복 아이템은 존재하지 않는다.
- 체력이 0이 되면 회복 여부와 관계없이 즉시 한 판이 종료된다.

## 탄약 완전 고갈

- 모든 무기의 보유 탄약이 0이 되어도 게임은 즉시 종료되지 않는다.
- 별도의 비상 탄약이나 자동 충전은 제공하지 않는다.
- 바닥에 남은 탄약이 있다면 플레이어는 회피하며 회수할 수 있다.
- 회수 가능한 탄약이 없다면 더 이상 적을 처치할 수 없고, 자연스럽게 압박을 견디지 못해 사망하게 된다.
- 이 상태가 지나치게 자주 발생하면 탄약 드롭량과 초기 탄약을 조정하되 구제 기능은 추가하지 않는다.

## 사망과 결과 흐름

사망 즉시 전투 입력과 시간 기록을 멈추고 결과 화면으로 전환한다.

결과 화면에는 다음 정보를 표시한다.

- 최종 점수
- 생존 시간
- 총 처치 수
- 헤드샷 처치 수
- 최고 콤보
- 무기별 처치 수
- 현재 브라우저의 개인 최고 기록
- 닉네임 입력과 제출 상태
- 제출 성공 후 상위 10개와 현재 점수 백분위

개인 최고 기록은 온라인 제출 성공 여부와 관계없이 갱신한다.

## 랭킹과 재시작

- 닉네임 입력과 점수 제출은 결과 화면에서 진행한다.
- 유효한 닉네임으로 제출에 성공하면 상위 10개와 백분위를 갱신한다.
- 제출하지 않거나 통신에 실패해도 재시작할 수 있다.
- 통신 실패 시 입력한 닉네임과 현재 결과를 유지하고 재시도할 수 있다.
- 재시작하면 시작 화면으로 돌아가며 클래스 선택, 체력, 탄약, 스킬, 점수, 콤보, 생존 시간을 초기화한다.
- 개인 최고 기록은 초기화하지 않는다.

## 한 판의 성공 기준

- 첫 플레이에서 1분 안에 적 처치와 탄약 획득을 경험한다.
- 3분 안에 두 무기 전환이나 스킬 사용이 필요한 상황이 발생한다.
- 5분 전후부터 세 적의 조합과 탄약 부족이 동시에 압박한다.
- 사망 원인을 결과 화면으로 전환되기 전에 이해할 수 있다.
- 결과 확인부터 재시작까지 불필요한 대기 없이 진행된다.
