# 게임 개요

## 문서 목적

이 문서는 Gulag-project의 전체 플레이 경험을 한눈에 설명한다. 세부 규칙은 관련 문서에서 정의하며, 이 문서는 기능 수를 늘리는 근거로 사용하지 않는다.

## 한 문장 소개

좁은 군사 산업 SF 아레나에서 세 클래스 중 하나를 골라 고정된 주무기·권총·고유 스킬을 운용하고, 적이 떨어뜨린 탄약을 회수하며 죽을 때까지 높은 점수를 기록하는 1인칭 생존 슈팅 게임이다.

## 기본 정보

| 항목 | 내용 |
| --- | --- |
| 장르 | 1인칭 무한 생존 슈팅 |
| 플레이 인원 | 1인 |
| 플랫폼 | 데스크톱 웹 브라우저 |
| 한 판 구조 | 시작 후 플레이어가 사망할 때까지 계속 진행 |
| 목표 생존 시간 | 일반 플레이어 기준 5~8분 |
| 맵 | 좁은 아레나 1개 |
| 클래스 | 척탄병, 공병, 저격수 |
| 무기 | 권총, 샷건, 라이플, DMR |
| 탄약 | 권총, 샷건, 라이플. DMR은 라이플 탄약을 공유 |
| 적 | 자폭형 적, 일반 근거리 적, 원거리 공격 적 |
| 주된 목표 | 전투 점수를 높이고 개인 최고 기록과 온라인 기록에 도전 |

목표 생존 시간은 강제 종료 시간이 아니다. 숙련된 플레이어는 8분을 넘어 계속 플레이할 수 있다.

## 핵심 재미

### 탄약을 얻기 위한 이동

탄약은 적이 쓰러진 위치에 떨어진다. 플레이어는 안전한 구역에 머물 수 없으며, 다음 전투를 이어가기 위해 위험 지역으로 들어가야 한다. 현재 클래스의 주무기와 권총 탄약만 같은 확률로 나오므로 남은 자원에 맞춰 두 무기를 바꾸는 판단이 중요하다.

### 세 적을 동시에 상대하는 우선순위 판단

자폭형 적은 폭발 위험으로, 일반 근거리 적은 지속적인 접근과 타격으로 공간을 빼앗고, 원거리 적은 안전한 이동 경로를 제한한다. 플레이어는 가까운 위협을 먼저 제거할지 원거리 적을 먼저 끊을지 계속 판단한다. 자폭을 다른 적에게 유도하면 위험을 점수 기회로 바꿀 수 있다.

### 생존과 고득점의 차이

가장 안전하게 오래 버티는 행동만으로는 최고 점수를 얻기 어렵다. 빠른 연속 처치와 헤드샷, 자폭형에는 권총, 일반 근거리에는 샷건, 원거리에는 라이플 계열을 맞춰 쓰는 판단이 높은 점수로 이어진다. 클래스 스킬의 사용 시점은 별도의 전투 판단을 만든다.

## 설계 원칙

1. **계속 이동하게 한다.** 탄약 위치와 적 조합이 플레이어를 전장 전체로 움직이게 해야 한다.
2. **공격을 명확히 예고한다.** 짧은 생존 게임이라도 피할 수 없는 피해처럼 느껴지면 안 된다.
3. **클래스 역할을 겹치지 않게 한다.** 고정 로드아웃과 고유 스킬은 사거리와 위험 대응 방식이 분명히 달라야 한다.
4. **전투 실력을 점수로 보여준다.** 생존 시간은 보조 점수이며 처치 방식과 콤보가 주된 점수 차이를 만든다.
5. **재도전을 빠르게 한다.** 사망 원인과 기록을 확인한 뒤 즉시 다시 시작할 수 있어야 한다.
6. **화면만 보고 이해할 수 있게 한다.** 피격, 공격 예고, 탄약 종류, 콤보 상태를 즉시 구분할 수 있어야 한다.

## 플레이어가 반복하는 판단

- 지금 가장 위험한 적은 무엇인가?
- 남은 탄약으로 어느 무기를 사용해야 하는가?
- 떨어진 탄약을 지금 회수할지, 적을 더 정리한 후 접근할지 선택해야 하는가?
- 자폭 적을 바로 처치할지 다른 적 가까이 유도할지 선택해야 하는가?
- 현재 적에게 맞는 권장 무기로 바꿀 것인가, 익숙한 무기로 계속 싸울 것인가?
- 콤보를 이어가기 위해 위험을 감수할 것인가?

## 한 판의 감정 흐름

| 구간 | 의도한 감정 |
| --- | --- |
| 시작 | 조작과 무기 역할을 빠르게 파악하는 여유 |
| 초반 | 탄약 회수와 세 적의 기본 대응을 익히는 자신감 |
| 중반 | 적 조합과 탄약 부족이 겹치며 생기는 압박 |
| 목표 시간대 | 콤보와 생존을 동시에 유지하는 높은 집중 |
| 사망 | 원인을 이해하고 기록을 갱신하고 싶은 재도전 욕구 |

## 성공한 플레이의 모습

- 선택한 클래스의 주무기와 권총을 남은 탄약과 적 거리에 맞춰 전환한다.
- 고유 스킬로 위기나 다수의 적을 처리한다.
- 자폭 적의 폭발로 다른 적을 함께 처치한다.
- 원거리 적의 공격 예고를 보고 이동한 뒤 빈틈에 반격한다.
- 탄약 드롭 위치를 기억하고 중앙과 외곽을 순환한다.
- 헤드샷과 연속 처치를 이어가면서도 피격 후 회복 시간을 확보한다.
- 사망 후 점수와 백분위를 확인하고 더 나은 전투 방식으로 재도전한다.

## 의도하지 않은 플레이

- 한 안전 지점에 머물며 적을 반복 처치하는 행동
- 주무기 하나만 사용해 탄약 부족이나 무기 전환이 발생하지 않는 상태
- 공격 예고를 보지 못하고 화면 밖 피해로 반복 사망하는 상태
- 콤보를 유지하려는 시도보다 단순 생존이 항상 높은 점수를 얻는 상태
- 탄약을 모두 소진한 뒤 기존 드롭에 접근할 가능성도 없이 오래 대기하는 상태

## 제작 기준

- Unity 6000.3.21f1과 URP 17.3.0 환경을 사용한다.
- WebGL에서 시작, 전투, 사망, 결과, 랭킹, 재시작의 전체 흐름이 동작해야 한다.
- 개발자 1명과 디자이너 1명이 정해진 일정 안에 완성할 수 있도록 콘텐츠 수를 고정한다.
- 새로운 시스템보다 조작감, 전투 가독성, 피드백, 안정성을 우선한다.
