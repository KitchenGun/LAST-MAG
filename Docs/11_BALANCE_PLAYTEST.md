# 밸런스와 플레이테스트

## 문서 목적

이 문서는 초기 기획 수치가 의도한 플레이를 만드는지 확인하고, 문제가 발견됐을 때 무엇을 먼저 조정할지 정의한다. 새로운 기능을 제안하는 대신 기존 수치와 표현을 조정한다.

## 최종 목표

- 처음 플레이한 사람이 목표와 조작을 빠르게 이해한다.
- 일반 플레이어가 주로 5~8분 사이에 사망한다.
- 세 클래스의 고정 로드아웃과 고유 스킬 역할이 구분된다.
- 적을 처치한 뒤 탄약을 얻기 위해 이동한다.
- 자폭형, 일반 근거리, 원거리 적의 대응법이 다르다.
- 적 능력치 상승 없이도 시간에 따라 압박이 계속 커진다.
- 공격적인 전투가 단순 생존보다 높은 점수로 이어진다.
- 사망 원인이 명확하고 결과 화면이 재도전을 유도한다.
- WebGL에서 시작부터 재시작까지 한 판의 흐름이 유지된다.

## 플레이테스트 단계

### 1단계: 코어 루프

대상 범위는 무기 1종, 자폭 적 1종, 탄약, 체력, 사망, 재시작이다.

확인 항목:

- 이동과 시점이 즉시 이해되는가?
- 사격과 적중이 분명한가?
- 적 처치 후 탄약을 회수하는 행동이 자연스럽게 이어지는가?
- 피격, 회복 시작, 사망 원인을 이해하는가?
- 한 판 종료 후 즉시 재시작할 수 있는가?

### 2단계: 콘텐츠 역할

대상 범위는 클래스 3종의 고정 로드아웃·고유 스킬, 적 3종, 점수와 콤보다.

확인 항목:

- 플레이어가 적 거리와 남은 탄약에 따라 주무기와 권총을 바꾸는가?
- 자폭형=권총, 일반 근거리=샷건, 원거리=라이플 계열의 권장 무기 선택이 자연스러운가?
- 수류탄, 로켓과 불릿타임이 각 클래스의 전투 방식을 구분하는가?
- 헤드샷 +30점, 스왑킬 +70점의 가산 보상이 과도하거나 부족하지 않은가?
- 자폭 적을 다른 적 근처로 유도하는 판단이 발생하는가?
- 원거리 적 때문에 한곳에 머물지 않는가?

### 3단계: 난이도와 기록

대상 범위는 5분 이후 난이도, 결과, 개인 최고 기록, 랭킹이다.

확인 항목:

- 5분까지 압박이 끊기지 않고 부드럽게 증가하는가?
- 5분 시점의 활성 적 목표 108명에서도 공격 예고를 읽을 수 있는가?
- 최종 점수가 전투 실력 차이를 보여주는가?
- 개인 최고 기록과 온라인 백분위를 구분하는가?
- 제출 실패가 결과 확인과 재시작을 막지 않는가?

### 4단계: WebGL 외부 검증

대상 범위는 최종 빌드 전체다.

확인 항목:

- 페이지 진입 후 플레이 시작이 가능한가?
- 마우스 시점과 사격 입력이 정상인가?
- 오디오가 플레이 시작 입력 후 재생되는가?
- 장시간 생존 후에도 적, 탄약, 피드백을 읽을 수 있는가?
- 사망, 결과, 제출, 재시작을 반복할 수 있는가?

## 조정 순서

한 번의 테스트 뒤 여러 값을 동시에 바꾸지 않는다. 한 가지 원인을 정하고 아래 순서에서 가장 앞선 항목 하나를 조정한 뒤 다시 테스트한다.

### 플레이어가 너무 빨리 사망할 때

1. 공격 예고 가독성 확인
2. 적 생성 위치와 동시 공격 방향 확인
3. 회복 대기 시간을 5초에서 4초 방향으로 조정
4. 자폭 피해 또는 원거리 피해 감소
5. 해당 시간대 동시 적과 생성 간격 완화

### 플레이어가 지나치게 오래 생존할 때

1. 안전 지점과 캠핑 동선 확인
2. 원거리 적 비율 증가
3. 생성 간격 단축
4. 해당 시간대 동시 적 목표 증가
5. 회복 대기 시간을 5초에서 6~7초 방향으로 조정

적 체력과 피해를 시간 경과에 따라 올리는 방식은 사용하지 않는다.

### 탄약이 지나치게 부족할 때

1. 획득하지 못한 탄약이 접근 불가능한 곳에 떨어지는지 확인
2. 탄약 드롭량 증가
3. 시작 보유 탄약 증가
4. 무기 피해와 적 체력의 관계 조정

비상 탄약이나 자동 충전은 추가하지 않는다.

### 한 무기가 지배적일 때

1. 해당 무기의 탄약 소비와 두 탄약의 드롭량 확인
2. 해당 무기의 유효 거리와 피해 조정
3. 헤드샷 +30점과 스왑킬 +70점이 위험에 맞는지 확인
4. 같은 클래스의 다른 무기 시작 탄약과 드롭량 조정

새 무기나 새 적을 추가해 해결하지 않는다.

### 콤보가 작동하지 않을 때

1. 좌측 중앙 `COMBO xN`과 탄환 5발이 HUD에서 보이는지 확인
2. 적 생성 간격이 고정 5초 유지 시간보다 긴 구간 확인
3. 고정 5초 유지 시간과 적 생성 간격 조정
4. 처치당 +10점 콤보 가산값 조정

## 필수 테스트 시나리오

### 조작과 생존

- 매 판 시작 전에 클래스 선택이 초기화되는지 확인한다.
- 이동, 점프, 사격, `1`·`2` 무기 전환과 `F` 스킬을 각각 수행한다.
- 피해 후 4초, 5초, 회복 중 재피격 상태를 비교한다.
- 체력 0에서 즉시 결과 화면으로 전환되는지 확인한다.

### 무기와 탄약

- 클래스 3종에서 주무기와 권총으로 적 3종의 일반 처치와 헤드샷 처치를 수행한다.
- 총성·총구 섬광·연기·카메라와 무기 반동이 같은 발사 프레임에 한 번씩 실행되는지 확인한다.
- 무기별 Pitch·Yaw·Random·Soft/Hard Cap·상승·회복 대기·복귀 값이 독립적으로 적용되고 모든 발에서 Yaw가 Pitch의 40% 이하인지 확인한다.
- 연사 중 실제 화면에 남은 반동만 누적되고 Soft Cap 접근 시 추가 상승이 줄며 Hard Cap을 넘지 않는지 확인한다. Pitch 한계 밖의 숨은 반동은 이후 다시 나타나지 않아야 한다.
- 권총·라이플·DMR 한 발은 기본 조준으로 완전히 복귀하고, 판정 시간 안에 두 발 이상 성공하면 마지막 복귀 시작값의 20%·35%·25%가 새 기본 조준에 남는지 확인한다.
- 샷건 반복 발사와 로켓은 항상 잔류 없이 복귀하며, 빈 탄창·발사 간격 차단·커서 잠금 클릭은 연속 판정 시간을 갱신하지 않는지 확인한다.
- 연속 사격 Return 중 재발사하면 예정 잔류가 취소되고 현재 보이는 오프셋만 누적되는지, 잔류 반영 프레임에서 화면이 순간 이동하지 않는지 확인한다.
- 무기 교체만 하면 이전 발사의 회복 프로필이 유지되고, 새 무기를 실제 발사한 순간에만 새 프로필로 변경되는지 확인한다.
- 반동 상승과 복귀가 초반에 빠르고 끝으로 갈수록 느려지는지 확인한다.
- Viewmodel이 매 발 초기화되지 않고 현재 위치·회전 속도에 새 충격을 더하며, 위치가 먼저 풀리고 회전은 약한 Overshoot 한 번 뒤 안정되는지 확인한다.
- 라이플 20발 연사에서 압축 자세 주변의 연속 운동이 유지되고 Viewmodel 오프셋과 속도가 무기별 1.5배 제한을 넘지 않는지 확인한다.
- 로켓 런처가 0.70초 동안 스프링 반동과 입력 잠금을 유지하고 투사체가 먼저 폭발해도 즉시 사라지지 않는지 확인한다.
- 라이플 연속 사격에서 총성 동시 재생이 최근 2개로 제한되고 지속음처럼 뭉개지지 않는지 확인한다.
- DMR 6발마다 두 원본 발사음이 각각 3회 재생되고, 동일 변형 연속과 같은 원본 3연속 없이 다음 셔플 주기로 이어지는지 확인한다.
- 구조물에는 주황색 스파크, 근거리·원거리 인간형 적에는 초록·올리브 파편과 4초/최대 20개 표면 흔적, 자폭형에는 기존 외피 파편만 표시되는지 확인한다.
- 샷건은 펠릿별 탄착을 표시하되 탄착음과 HUD 명중 피드백은 격발당 한 번인지 확인한다.
- 같은 적을 서로 다른 무기로 처치해도 무기 종류만으로 추가 점수가 생기지 않는지 비교한다.
- 주무기와 권총 탄약이 50:50으로 나오고 다른 클래스 탄약은 나오지 않는지 관찰한다.
- 탄약 상자 하나가 권총 `15→5`, 샷건 `8→3`, 라이플 `50→20`, DMR `12→4`의 고정량을 지급하는지 확인한다.
- 저격수의 DMR 사격이 라이플 탄약을 소비하고, 주무기 드롭이 파란색 라이플 탄약 4발을 지급하면서 DMR 실루엣과 `+4 DMR AMMO`를 표시하는지 확인한다.
- 현재 무기가 아닌 탄약을 획득한다.
- 보유 탄약 최대치에서 같은 탄약과 접촉한다.
- 모든 탄약을 소진하고 기존 바닥 탄약이 없는 상태를 플레이한다.

### 클래스 스킬

- 척탄병에서 `F`로 무장하고 좌클릭으로 수류탄을 12m/s 포물선으로 던져 `4.5/5.5/6.5초`에 세 번 폭발시킨다.
- 공병 로켓이 충돌 즉시 폭발하고 미충돌 시 5초 후 공중 폭발하는지 확인한다.
- 수류탄이 첫 폭발 위치에 고정되어 메시를 유지하고, 같은 적과 플레이어가 범위에 남으면 매회 90·45 피해를 받는지 확인한다. 로켓 150·4m와 자기 피해 75 규칙은 유지한다.
- 수류탄·로켓 자기 피해로 사망하면 결과 화면에 각각 `GRENADE SELF-DAMAGE`, `ROCKET SELF-DAMAGE`가 표시되는지 확인한다.
- 수류탄·로켓 무장 중 `F` 재입력이 무시되고 무기 전환만 비용 없이 취소하는지 확인한다.
- 세 번째 수류탄 폭발 뒤 10초, 로켓 단일 폭발 뒤 14초 쿨다운이 시작되는지 확인한다.
- 불릿타임이 5초간 세계와 플레이어 이동·점프·중력, 무기 모델 반동, 총구 화염·연기·탄도 파티클과 배경음악을 35% 속도로 늦추되 Aim Recoil·Fire Impulse와 RPM은 실시간을 유지하고 종료 뒤 20초 쿨다운을 시작하는지 확인한다.
- 월드가 0.15초 동안 흑백으로 전환·복귀하고 Overlay HUD 색상은 유지되는지 확인한다.
- 불릿타임 중 조준·사격 속도, HUD, 체력 회복, 생존 점수와 콤보 타이머가 실시간을 유지하는지 확인한다.
- DMR이 최대 초당 4발로 발사되고 세 충돌체에 `60→40→20` 피해를 주며 벽과 적을 함께 관통하는지 확인한다.
- DMR 일반 모드에서 기본 조준선만 숨고 HitMarker는 유지되며, 우클릭 시 FOV `90→45`, 감도 50%, 검은 비네팅과 조준선이 0.12초 안에 적용되는지 확인한다.
- 우클릭 재입력과 무기 교체·커서 해제·사망에서 FOV·감도·비네팅이 원래 상태로 복원되는지 확인한다.
- DMR 각 관통 단계의 헤드샷이 2배 피해를 주고 모든 사격에 최종 지점까지 탄도가 표시되는지 확인한다.

### 적과 난이도

- 자폭 적을 플레이어 가까이에서 폭발시킨다.
- 자폭 적을 다른 적 근처에서 처치해 연쇄 폭발을 만든다.
- 원거리 적이 이동, 정지, 예고, 사격, 재배치하는 흐름을 확인한다.
- 일반 근거리 적의 공격 방향 고정과 측면 회피를 확인한다.
- 지상과 상부에 플레이어를 두고 세 적의 대응을 확인한다.
- 1분, 3분, 5분, 8분 시점의 동시 적과 생성 압박을 비교한다.

### 점수와 기록

- 자폭형 50점, 일반 근거리 70점, 원거리 100점의 기본 점수를 비교한다.
- 적 3종 × 클래스별 장착 무기 × 헤드샷 여부에서 무기 타입 매칭 점수가 없고 헤드샷 +30점만 적용되는지 검증한다.
- 서로 다른 직접 총기 처치를 2초 이내에 이어 +70점 스왑킬을 받고, 같은 총기·2초 초과·중간 수류탄·로켓·연쇄 처치에서는 받지 않는지 확인한다.
- 수류탄·로켓, 불릿타임 총기 처치, 스킬 유발 연쇄가 `B + 2B`로 총 300% 기본 점수를 받는지 확인한다.
- 일반 플레이어 귀속 연쇄는 기본 점수와 콤보 가산점만 받고 자연 자폭·비귀속 폭발은 무득점인지 확인한다.
- 동시 처치도 처치마다 `C`를 1씩 올려 `10 × (C-1)`을 적용하고 마지막 처치 뒤 5초로 갱신하는지 확인한다.
- 콤보가 10을 넘어 계속 증가하고 정확히 5초 만료 시 0으로 초기화되는지 확인한다.
- 좌측 중앙 탄환이 `5→4→3→2→1→0`으로 오른쪽부터 줄고, 처치 시 5발로 복구되며, 카운트가 1콤보 흰색에서 10콤보 붉은색으로 변하는지 확인한다.
- 크로스헤어 하단 피드가 최신 점수를 상단에 두고 최대 4줄을 재사용하며 2.25초 유지와 0.3초 페이드를 지키는지 확인한다.
- HUD 누적 점수, 결과 점수, 개인 최고점, 온라인 제출 점수가 일치하고 결과에는 `MAX COMBO xN`만 표시되는지 확인한다.
- 기존 `Layer_ScoreCombo/TimeText`가 `00:00`부터 실시간 `MM:SS`로 표시되고 `59:59→60:00` 전환과 불릿타임 중 경과가 유지되는지 확인한다.
- 개인 최고 기록을 갱신한 뒤 페이지를 새로고침하고 브라우저를 다시 실행한다.

### 랭킹

- 2자와 12자의 유효 닉네임을 제출한다.
- 1자, 13자, 공백, 특수문자를 포함한 닉네임을 제출한다.
- 같은 닉네임과 같은 플레이어의 여러 점수를 제출한다.
- 같은 점수 두 개를 제출해 순서와 백분위를 확인한다.
- 통신 실패 후 재시도와 재시작을 각각 수행한다.

### WebGL 전체 흐름

- 시작 화면 좌측 하단의 버전 문자열이 `vMAJOR.MINOR.PATCH · WEB-BUILDID` 형식으로 보이고, 배포한 빌드마다 `BUILDID`가 달라지는지 기록한다.

- 처음 접속한 브라우저에서 시작부터 사망까지 플레이한다.
- 결과 확인, 닉네임 제출, 랭킹 표시, 클래스 선택 화면으로 돌아가 다음 런을 시작한다.
- 8분 이상 생존한 뒤 사망하고 다시 시작한다.
- 다른 PC의 브라우저에서 동일한 흐름을 반복한다.

## 문제 기록 형식

각 문제는 다음 정보만 기록한다.

- 테스트 환경
- 경과 시간
- 사용 무기
- 당시 적 조합
- 관찰한 행동
- 의도한 행동
- 조정할 수치 한 개
- 재검증 결과

## 최종 통과 기준

- 처음 플레이한 사람이 30초 안에 기본 목표를 설명한다.
- 일반 플레이어의 생존 시간이 주로 5~8분에 모인다.
- 세 클래스마다 주무기·권총·고유 스킬의 선택 이유가 있다.
- 자폭형, 일반 근거리, 원거리 적의 사망 원인과 대응법이 구분된다.
- 5분 이후에도 적 공격 예고와 탄약 종류를 읽을 수 있다.
- 개인 최고 기록이 같은 브라우저에서 유지된다.
- 랭킹 실패가 한 판의 결과 확인과 재시작을 막지 않는다.
- WebGL에서 시작부터 두 번째 런 시작까지 진행 차단이 없다.

## WebGL 108명 성능 검증 기록

- 빌드: Development WebGL, 1280×720, `?stressEnemies=108` 측정 후 동일 소스로 `0.1.2` 재빌드
- 조건: 108명 도달 후 10초 워밍업, 60초 연속 측정
- 결과: 평균 81.2 FPS, 프레임 p95 12.00ms, CPU p95 12.10ms, 33ms 이상 프레임 0회
- 풀 회귀: 종류별 36명씩 재활성화할 때 풀 총량 증가 없음, Editor Play Mode 기준 6ms
- 브라우저 콘솔: 전투 오류 0, 오디오 채널 고갈 경고 0
- GPU p95: WebGL FrameTiming에서 값이 제공되지 않아 `not_run`
- 브라우저 범위: 인앱 Chromium에서 통과했으며 외부 Chrome·Edge는 연결되지 않아 `not_run`
- 판정: CPU 목표를 통과하여 그림자 거리, 추가 광원, HDR 설정은 유지한다.
