# 플레이어 캐릭터

## 문서 목적

이 문서는 플레이어의 조작, 전투 역할, 체력과 피해, 생존 판단을 정의한다.

## 플레이어 판타지

플레이어는 좁은 전함 내부에서 다수의 적에게 포위되지만, 빠른 이동과 정확한 사격으로 전장을 계속 순환하는 전투원이다. 가만히 버티는 인물이 아니라 적 사이를 뚫고 탄약을 회수하며 공격 흐름을 이어가는 인물로 느껴져야 한다.

## 기본 조작

| 행동 | 입력 | 규칙 |
| --- | --- | --- |
| 이동 | `W`, `A`, `S`, `D` | 지상에서 전후좌우 이동 |
| 시점 | 마우스 이동 | 1인칭 카메라 회전, 로비 설정의 `0.00~1.00` 감도 배율 적용 |
| 사격 | 마우스 버튼 | 현재 무기의 투사체 발사 |
| 점프 | `Space` | 높이 차와 장애물 통과 |
| 주무기 선택 | `1` | 클래스 주무기로 즉시 전환 |
| 권총 선택 | `2` | 권총으로 즉시 전환 |
| 고유 스킬 | `F` | 척탄병·공병은 무장, 저격수는 즉시 활성화 |
| 일시정지·설정 | `Esc` | 게임과 오디오를 정지하고 SettingsPanel을 열며 다시 누르면 재개 |

마우스 휠 무기 전환, 달리기, 앉기, 대시는 최초 범위에 포함하지 않는다. DMR 조준 확대는 로비 설정에서 우클릭 `TOGGLE` 또는 누르는 동안 유지하는 `HOLD`를 선택한다.

## 공통 설정

- 마우스 감도는 기존 감도를 `1.00`으로 보고 `0.00~1.00` 배율로 조절한다.
- 마스터 볼륨은 `0~100%`로 조절하고 모든 씬의 전체 음향에 적용한다.
- 줌 방식의 기본값은 `TOGGLE`이며 설정은 브라우저에서 다음 실행에도 유지한다.
- 로비와 게임 중 SettingsPanel은 같은 설정값을 사용하며 변경 즉시 저장·적용한다.
- 게임 중 패널을 열면 현재 무기·탄약·줌·무장 스킬 상태를 보존한 채 전투를 정지한다.

## 이동 역할

- 이동은 적의 공격을 피하는 수단이자 탄약을 회수하는 수단이다.
- 중앙 플랫폼과 외곽 순환로 사이를 막힘없이 오갈 수 있어야 한다.
- 점프는 높이 차와 낮은 장애물을 넘는 기본 행동으로 사용한다.
- 플레이어가 한 지점에서 계속 사격하는 것보다 전장을 순환하는 편이 유리해야 한다.
- 이동 중에도 현재 체력, 탄약 위치, 자폭 적의 접근, 원거리 공격 예고를 확인할 수 있어야 한다.

## 체력 규칙

| 항목 | 초기값 | 조정 범위 |
| --- | ---: | ---: |
| 최대 체력 | 100 | 고정 |
| 회복 대기 시간 | 5초 | 4~7초 |
| 초당 회복량 | 20 | 10~30 |
| 회복 한도 | 최대 체력 | 고정 |

- 피해를 받으면 회복 대기 시간이 다시 시작된다.
- 회복 중 피해를 받으면 회복이 즉시 중단된다.
- 회복은 전투를 잠시 피한 보상이며 회복 아이템을 대신한다.
- 최대 체력 이상으로 회복되지 않는다.
- 체력이 0이 되면 점수·생존 시간·사망 원인을 즉시 확정하고 입력을 중지한다. 이후 약 3.3초의 쓰러짐 연출 뒤 결과 화면으로 전환한다.

## 피격 후 판단

피해를 받은 플레이어에게는 다음 세 가지 선택이 생겨야 한다.

1. 안전한 동선으로 이동해 5초의 회복 시간을 확보한다.
2. 위험을 감수하고 가까운 적을 처치해 탄약과 콤보를 유지한다.
3. 자폭 적을 다른 적에게 유도해 직접 사격 부담을 줄인다.

자동 회복이 전투를 중단하고 숨어 기다리는 행동만 유도하면 안 된다. 원거리 적의 위치와 탄약 드롭은 플레이어가 지나치게 오래 숨지 못하게 해야 한다.

## 무기 운용

- 매 판 시작 화면에서 척탄병, 공병, 저격수 중 하나를 다시 선택한다.
- 각 클래스는 `1`번 주무기와 `2`번 권총만 보유한다.
- 세 클래스의 체력과 이동 속도는 같으며 별도 패시브는 없다.
- 무기 전환과 고유 스킬 사용은 탄약 부족, 적 거리, 점수 기회에 대응하는 기본 판단이다.
- 무기마다 탄창과 예비 탄약을 나누지 않고 보유 탄약 하나만 관리한다.
- 발사 입력 1회마다 현재 무기의 보유 탄약 1발을 소비하며 재장전하지 않는다.
- 현재 무기의 보유 탄약이 0이면 발사되지 않으며 탄약이 남은 무기로 직접 전환한다.
- 모든 탄약을 소진해도 별도 근접 공격이나 비상 공격은 제공하지 않는다.

## 숙련도 차이

### 처음 플레이하는 사람

- 선택한 클래스의 주무기로 적을 처리하고 권총으로 전환한다.
- 공격 예고를 보고 이동한다.
- 탄약 색, 무기 번호와 `F` 스킬 상태의 관계를 익힌다.
- 피격 후 회복 시간을 확보한다.

### 숙련된 플레이어

- 자폭형에는 권총, 일반 근거리에는 샷건, 원거리에는 라이플 계열을 선택하고 헤드샷을 노린다.
- 스킬의 효과 종료와 쿨다운 시점을 계산해 사용한다.
- 자폭 적을 적 무리 가까이 유도한다.
- 콤보 종료 전에 다음 적을 처치한다.
- 바닥 탄약 분포를 보고 다음 무기를 미리 선택한다.
- 회복을 기다리면서도 적 위치와 탄약을 이용해 공격 흐름을 완전히 끊지 않는다.

## 상태 전달

- 피격 시 화면과 소리로 피해 방향과 강도를 전달한다.
- 회복 대기 중에는 체력이 회복되지 않는다는 사실을 구분할 수 있어야 한다.
- 회복 시작과 최대 체력 도달을 과도하지 않은 피드백으로 알린다.
- 체력 50% 이하에서 낮은 체력 경고음을 한 번 재생하고, 60% 이상 회복해야 다시 경고한다. 화면 가장자리 비네팅은 기존처럼 받은 피해량에 비례한다.
- 현재 무기의 보유 탄약이 0이면 HUD의 탄약 표시를 짧게 강조한다.
- 스킬의 준비·활성·쿨다운 상태와 남은 시간을 HUD로 전달한다.
- 사망 직전 마지막 피해 원인을 알아볼 수 있어야 한다.
- 사망 시 `SFX_Death_VitalSignsLow`를 최우선으로 재생하고, 현재 무기 또는 준비 중인 스킬 메시 하나만 물리적으로 떨어뜨린다.

## 성공 기준

- 조작 안내만 보고 이동, 사격, 점프, 무기 전환과 스킬 사용을 수행할 수 있다.
- 피격 후 회복이 시작되는 조건과 중단되는 이유를 이해할 수 있다.
- 3분 안에 최소 두 종류 이상의 무기를 사용하게 된다.
- 플레이어가 탄약을 얻기 위해 중앙과 외곽을 오간다.
- 모든 탄약을 소진한 상황이 발생해도 게임 규칙 오류로 오해하지 않는다.
